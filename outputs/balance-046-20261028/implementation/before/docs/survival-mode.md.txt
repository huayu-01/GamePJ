# 生存试炼：整合、参考与首版设计

2026-10-25设计，2026-10-26接入。用户已确认保留手动战斗和12分钟生存阶段。以下数值是便于验证节奏的首版预设，场景是可玩的首版庭院，最终美术和长局平衡仍需试玩。

独有构筑见[专属构筑实现](survival-builds.md)：四条路线十二项已进入本模式限定池，总目录103项，原91项继续保留。等级2起每隔3级及强敌遗物提供专属选择，信标仍提供普通收益。

## 先整合已有内容

- 角色与战斗：两角色六武器、手动瞄准与技能槽、真实动画事件、蓄力快照、护甲、霸体、击退与导航均复用现有实现。
- 内容：20种地面敌人、原91项增幅加12项模式专属、11枚携带符文、现有首领；另已接入[33项精英特性](elite-traits.md)，虫洞／筑墙／飞弹减速暂缓。不新增飞行单位。
- 流程：复用出击摘要、`PlayerLoadout`、`RunBuild`、奖励选择会话、暂停、整局取消回退与单次结算。所有运行期加载从首次读取起使用`RuntimeResources`。
- 模型：三叶旅童已有64项试装检查和角色A三武器真实伤害验证。正式替换仅改变猎手视觉档案引用，身体、数值、角色Id与技能槽继续使用原配置；接入后再验正式基地、关卡、动画与换装。

## 先设计场景：暮光回廊

一张约104米见方的森林废墟庭院。中央月井、宽十字通路和外圈主路形成可绕行空间；障碍集中成岛，主路净宽至少6米，避免重型敌人堵死必经点。地面平整，低矮遗迹允许玩家借跳跃换线。

- 南侧：独立入场区、路面与入口标识，出生区与第一座信标相连。
- 中央：月井与开放战斗区，蓝绿色纹样提供方位参照，主要攻击预警保留清晰底色。
- 西侧：琥珀色锻炉废墟；东侧：青色晶簇；北侧：残破拱门。三处地标帮助自由镜头下辨认位置。
- 三处信标分别位于不同象限，可接近启动并在范围内守候；不完成也能推进时间。完成后取得构筑收益，全部完成可削弱终局首领。
- 外缘：树群、碎岩和实体边界收束视线；树冠及高大装饰尽量退到战斗外围。地面、阻挡与导航分开制作，所有生成点检查可达性、距离及身体净空。

庭院单独给近镜头树叶设置9至15米距离渐显；保留树干和碰撞，避免第三人称相机进入树冠后遮住战斗。原森林场景和自然资源预制体不受此调整影响。

场景以已有风格化资源及可编辑几何组装，实际可玩画面用于验收，不用概念图代替场景。

## 再设计关卡内容

| 阶段 | 目标节奏与敌人组合 |
|---|---|
| 开场 | 基础近战为主，少量快速单位；让玩家学习拾取与第一次升级 |
| 早期 | 加入自爆与普通远程，拉开近身和走位压力 |
| 中期 | 加入持盾、投掷及遁地追踪，信标成为可选路线目标 |
| 中后期 | 重击、回旋和跳扑组合，出现明确提示的强化敌人 |
| 收束 | 提高压力预算和补给价值，保留攻击前摇与范围预警 |
| 终局 | 停止普通增援，生成首领；击败后清理战斗并激活撤离门，互动后只结算一次 |

普通增援按时间恢复生成预算，同时受存活压力、数量与待生成上限约束。敌人的行为压力继续决定费用，生成失败不扣费；生成预告后仍复核合法位置。首领、精英和普通敌人的来源归属明确，友方召唤、场景清理与重复死亡回调不产出额外经验。

经验使用有上限的集中绘制拾取物；达到上限时合并数值，保留累计经验。多级连升排队领取，暂停及选择期间时间不推进。奖励沿用角色／武器限定、前置、互斥和获取次数；无合法候选有明确回退，不凭空生成无效增幅。

精英里程碑位于3／6／9分钟，击败后留下单次领取遗物；随机精英与里程碑精英保留基础护甲和表现，并可从[共同目录](../Config/EliteTraits/catalog.tres)承载一个适配特性。以至多4只原定敌人、至多20秒为一个固定批次，阶段切换也结束旧批；同批只抽一种，不逐只重抽，12种较强特性预设最多一只承载。基础费用加 `ExtraCost` 后同时检查预算与存活压力，生成失败撤销预留。

召唤特性只出有限一批免费随从，不扣本模式生成预算；随从按原型压力加入人数／存活压力与清场，保留来源，不继承特性、不补员、不发经验／遗物，也不成为猎令候选或完成收益。暂停与奖励选择不推进危险计时；终局切换、首领死亡、取消和离场统一停止附加特性与残留伤害。

精英特性区域在本模式的 `EliteHazardWorld` 内共享24个总名额、每来源最多6个，包含跨批次仍存续的精英区域。原型投射物和技能危险沿原系统限制，尚未合并成跨原型的全场统一危险额度。

阶段敌种由本模式时间表决定，不使用旧遭遇节点各自的计时门槛。信标从开局可选，按F启动后圈内累计8秒、离开每秒退0.5秒；完成恢复15%生命并提供一次增幅，全部完成令首领生命再乘0.7。首领基础生命在全局敌人倍率上再乘0.8；首领仍使用独立技能构筑，不抽普通精英特性。

首次升级需要14经验，后续每级增加7；敌人每点压力产出2经验。每三级升级与目标收益可选全类合法增幅，其他升级优先强化；无该类候选时回退全类，全部耗尽时恢复15%生命。经验显示最多384份，靠近4米自动吸收。

## 制作与调参入口

- 基地 `SurvivalGate` 位于 `(-10,0,-5)`，原冒险门保留。新门先打开目的地摘要，返回调整不会创建回退点；确认后进入[独立场景](../Scenes/Survival.tscn)。Esc的取消冒险与死亡返回沿用共享整局服务。
- [目的地资源](../Config/Modes/survival_destination.tres)引用[生存配置](../Config/Modes/twilight_survival.tres)，摘要与实际运行共读设置。六个 `SurvivalPhase` 配置阶段起点、敌种池、预算恢复、压力／人数上限、生命／伤害倍率和精英概率。
- `SurvivalDirector` 的 `TraitCatalog`／`EnableEliteTraits`／`EliteTraitBatchSize`／`EliteTraitBatchSeconds` 控制精英目录、开关和批次；默认共用33项目录、4只／20秒。资源行的 `MaxCarriers` 控制承载数量，不等于批次人数。
- [SurvivalDirector](../Scripts/Run/Survival/SurvivalDirector.cs)只编排模式；`RunController`继续负责配装、构筑、取消与结算。以后新增模式可分别继承 `RunModeDefinition` 和 `RunModeController`，用目的地资源接入同一出击摘要。
- [庭院场景](../Scenes/Levels/SurvivalArena.tscn)可以在Godot直接编辑。[初始制作脚本](../_tools/build_survival_content.py)会重写它拥有的四个新场景／配置文件；手工编辑后不要无意重跑覆盖。
- 升级、信标和遗物复用正式奖励池；新增增幅仍按[新增内容操作](content-authoring.md)配置，无需修改模式控制器。

## 接入与验收边界

新模式通过独立场景和模式控制器提供计时、成长、生成与撤离；共享整局控制器继续负责配装、符文、构筑、取消和结算。旧冒险仍使用原阶段控制器。新入口摘要明确目的地、时长及玩法。

需验证入口可达、摘要与返回调整、导航连通、预算／净空、经验归属、升级暂停与队列、信标、首领与出口、死亡、整局回退、迟到回调清理，以及两角色六武器和新模型的正式流程。真实存档受五文件指纹保护，写盘验证使用独立用户目录。

精英接入新增 `_tools/verify_elite_traits.ps1`，包含防御、危险、机动／投射和双模式集成四类无头／渲染专项，当前专项已验证。范围接触、荆棘跳跃、同波单特性、免费有限召唤与原节点／生存归属共用真实入口；最终8次精英专项435项断言、19项旧流程、生存构筑65／69项及7次GC通过，见[本批交付证据](../Logs/evidence/elites-delivery-20261026.json)；下面原模式验收仍作为历史基线保留。

2026-10-26验收：新模式无头55项、真实渲染62项通过。模式链路用12秒副本加速六阶段与首领验证，再从真实基地入口进入正式12分钟配置；覆盖经验、连升暂停、重复领取、精英遗物、三信标、首领、主动撤离、单次结算、取消与死亡返回，最后执行完整GC。实际截图见[庭院总览](../Logs/evidence/survival/overview.png)、[出生视角](../Logs/evidence/survival/play.png)、[正式12分钟入场](../Logs/evidence/survival/production.png)；出生视角中计时为测试副本的12秒，正式配置未缩短。
