# 敌人动漫三渲二上色样板

日期：2026-10-21。用户明确补充：模型需要卡通动漫的三渲二上色，有明亮颜色和涂绘感。当前在 `Scenes/Debug/NatureArtLab.tscn` 的蘑菇、小法师、石人上试用；不修改已经认可的形体。

- `palette.json`：按源材质名称维护亮部、阴影、提亮色，阴影用有色的冷暖关系，避免直接把底色乘成灰黑。
- `anime_paint.gdshader`：清楚的主明暗色块，少量提亮档，边界使用屏幕导数抗锯齿；轻微且稀疏的程序化涂绘变化，不依赖人工笔触贴图。
- `shroom_regions.png`：蘑菇的固定 UV 区域遮罩，R 为菌盖、G 为眼白、B 为瞳孔及口内。根据现有 GLB 静态位置与原贴图生成，修正帽沿内侧串绿、眼白杂色和菌柄底部浅色碎斑；不受缩地变形影响。
- `anime_outline.gdshader`：仅包围角色网格的细深紫轮廓，眼睛、光球和菌盖斑点不额外描边。
- `EnemyAnimePreview.gd`：只接管三只样件的表面材质。原 GLB／Blender 工程、角色造型、骨骼和动作不变。使用表面覆盖而非整网格覆盖，继续允许既有受击／攻击短闪暂时覆盖身体。

蘑菇重新映射菌盖和菌柄颜色，原混元贴图只保留面部标记，减轻贴图烘焙暗部与场景光照叠加后的灰暗。小法师保留漆黑主体，用鲜紫帽、暖色眼睛和少量边缘受光增强辨识度；没有恢复手臂。石人使用浅奶绿石色、偏冷阴影、鲜绿苔藓和暖色皮革。

程序化笔触属于本版材质的上色提案，尚未逐个绘制人工笔触贴图。几何面数和骨骼不增加；细描边会增加一次对应网格的绘制。当前以样板画面确认方向，未推广到生产关卡的全部材质。

遮罩维护：从项目根目录运行 `python ArtSource/Tools/build_shroom_paint_mask.py`（NumPy、Pillow）。只读取现有蘑菇 GLB，写入遮罩 PNG，不需要 Blender 或重新导出模型。遮罩是区域数据，Shader 按线性数据采样；模型 UV 或造型改变后才需重建。

进入样板后，**F12** 在动漫上色与原材质之间切换；F10 选观察镜头，F11 继续演示动作。命令行参数 `--enemy-art-original` 可固定为原材质，用于同机位取证。

实现使用 [Godot 官方空间着色器接口](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html)的 `fragment`、`light` 与 `next_pass` 材质机制，未使用屏幕截图重绘或后期滤镜替代游戏画面。
