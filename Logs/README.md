# 日志与验证证据

本目录由`.gdignore`排除Godot资源扫描，不参与运行资源导入。

| 目录 | 用途 | Git策略 |
|---|---|---|
| `runtime/` | 编辑器及开发工程运行的GameLog | 本地忽略 |
| `validation/` | 验证脚本stdout、stderr、构建输出和存档指纹 | 本地忽略 |
| `evidence/` | 文档引用的完整验收记录与历史比较基线 | 保留版本管理 |
| `archive/` | 从工程根目录收拢的旧调试输出 | 本地忽略 |
| `maintenance/` | 清理清单、校验结果与改动前备份 | 本地忽略 |

导出游戏的运行日志仍写入`user://logs/`；开发工程无法写本目录时也回退到该位置。截图和模型验证JSON继续使用原有路径，本轮不搬动外部美术产物。

维护中的PowerShell验证入口通过`_tools/LogPaths.ps1`创建目录。后续脚本不得把输出重新散落在工程根目录或`docs/`。`evidence/`中的基线不能按日期自动删除；新内容引起基线变更时应解释规则变化并保留原始证据。
