# 角色建模：参考方法与制作经验

记录日期：2026-10-25。来自“三叶旅童”本轮制作与用户反馈，后续继续增补。新模型制作前先读此页，再读对应资产说明；用户后来的具体要求优先于旧记录。

## 用户确认的制作方法

用户原话：**“制作时要多找参照物模仿……有其形无其象……（换皮不换骨）。”**

本项目据此采用的做法：先学准参考的比例、轮廓、体积、结构关系与材料表现，再替换成本项目的面具、配色、图案和其他识别元素。不能只借一个斗篷、面具等表面元素，就凭想象重新拼出一套不同的比例与体积。

这里把“骨”作为设计结构来理解：大头短身的比例、胸腹与腿脚的体积、帽沿和后帽顶的关系、布片的悬挂与折叠。具体骨骼名称、骨数、拓扑和绑定方式仍按模型与项目行为决定。

制作时多找相近参照。选定一个清楚的主参考把握整体，再用侧面、背面、线框、动作和实物材料参照解决局部问题。缺少角度时继续找参照，避免靠正面图猜完整体积。

### 2026-10-26补充：描述不能代替完整的形体观察

用户原话：**“制作模型时你能仔细先拆解将要制作图形的每个细节，之后再逐渐细节去参照和制作，而不是只是制作个符合描述就收工的模型，很多东西都是描述是准确的但是不完全描述所有。”**

后续制作以这条要求为固定工作方法：文字用于确定方向与明确边界，不能当作穷尽全部设计细节的清单。必须继续观察参考中未被文字逐一说出的比例、弧度、截面、厚度、叠压、负空间、褶皱受力和材料软硬，落实到真实形体。不能把“部件齐全”“关键词命中”或技术检查通过当作美术完成。

1. **先列参考拆解表。** 按整体剪影→头身与宽厚比例→各部件轮廓和截面→部件之间的覆盖／连接／间隙→表面厚度与转折→材料表现→配色与留白→动作中的变形逐项记录。每项写清参考依据、当前差异、拟采用的改法和核对视角。
2. **区分证据与补全。** 分开记用户明确要求、参考可直接观察的细节、背面等缺失信息的暂定补全。缺失信息先寻找相近实物／多角度资料；自行补全要明确标注，不能称为用户已确认，也不能借补全添加多余装饰。用户后来的修改仍优先。
3. **从大形逐层做到局部。** 先灰模对齐整体体积与负空间，再落实面具曲率、帽沿弧线、衣料叠压、自由边、关节和连接等结构；最后才补图案、少量凿痕与颜色。局部细节不对时回到参考修形，不能用更多纹理掩盖。
4. **用同角度比较形体。** 最少检查正、侧、背、三分之四视角，以及实际游戏镜头；同镜头并排核对比例、外轮廓与关键转折。必要时单独显示部件、截面、线框或临时隐藏衣物，看清内部支撑和遮挡关系。
5. **按材料检查细节是否成立。** 布有悬挂、松垂、牵拉和宽窄变化的褶；木有厚度、切面、适量倒角和雕刻转折；石有体块之间真实的拼接与关节空隙。低面数与简单色彩要求更准确的结构选择，不等于用球、锥或圆柱代替所有材料。
6. **在动作中复核。** 检查待机、最大迈步、起手、命中、收招、受击与死亡等关键姿态，尤其衣物净空、武器朝向、足底、图案贴合和前后侧轮廓。仍按当前敌种／角色真实需要选动作，不擅自扩大动作清单。
7. **交付前做差异复盘。** 对照拆解表逐条标记已对齐／仍有差异／暂缺参考，附真实模型截图；先主动修正明显偏差，再交用户评审。技术验证与美术相似度分别说明，未经用户认可不称最终定稿。

本轮敌人先按[文字美术计划](../docs/enemy-art-plan.md)供用户选择和整改，之后再生图挑选，选定后才逐个做详细参考拆解、模型、绑定与场景验证。这一顺序不是要求每一个可逆的制作细节都再次申请许可；已选方向中的常规细化应自主推进并给出可对照结果。

2026-10-26主题补充：当前角色／敌人属于**魔幻丛林风**，用户希望有明显、熟悉的丛林元素。后续优先让果壳、宽叶、藤蔓、根须、树皮、菌盖与苔石参与角色的大轮廓、穿戴和身体结构，选适合当前物种的几项组合；保持低多边形与简单色彩，不把“更多丛林元素”理解成密集碎装饰。持锤石头人已被用户取消，纯岩块Plus方向保留。当前首批选择为E01-B、E03-B、E07-A、E15-A，先看E01-B图稿。

## 开始建模前先拆参考

1. 收集正面、侧面、背面及三分之四视角；有线框或动作展示时一起看。保存公开来源链接和可用于后续对照的参考图。
2. 先拆大形体：头身比、头与肩／腰臀的宽度关系、身体厚度、腿长腿围、脚掌大小和站距。
3. 再拆部件关系：面具覆盖多少兜帽、帽沿如何接近额头、后帽顶怎样形成弧线、领围如何叠压、斗篷从哪里悬挂。
4. 确认材料的形体语言：木板的平面、厚度、倒角和凿痕；布料的受力褶、松垂、自由边和翻折。
5. 先做粗模与多视图对照，再补图案和小细节。用户画出的轮廓线应直接落实到模型形体。

对照尽量使用接近的镜头、视角和构图。展示应来自实际Blender模型；正面好看后，还要看正侧面和背面。比例有疑问时可临时隐藏斗篷，直接检查身体结构。

## 本轮返工中值得保留的结论

| 反馈或问题 | 以后采用的做法 |
|---|---|
| 面具越做越像圆盘，偏离猫头鹰轮廓 | 先对齐用户标线的上挑尖角、宽直脸颊和收尖下颌，再做木板厚度与雕刻；减少泛用球面和圆盘替代。 |
| 兜帽太大，后来又把整顶帽压得太低 | 分开控制前沿和后帽顶：前沿贴近面具额头上缘或略低，后帽顶高一些，再向后回落；必须用侧面验证弧线。 |
| 斗篷像硬壳，缺少布料感 | 避免规则锥形、等距贯穿的纵褶和粗亮压边。先包住肩部，再安排疏密、深浅、走向不同的垂褶，前襟和下摆带少量翻折。 |
| 木头与布料缺少区分 | 保留木面具的平面与棱角；布面可使用较柔和的明暗，但仍保持低面数和简洁色块。不能只靠加细纹理补救错误的大形体。 |
| 简化面具内部时误删了身体 | 局部简化只作用于指定部位。**“面具内部不需要东西”“不需要手”不等于“不需要躯干和双腿”。** |
| 身体补回后太瘦 | 以参考的整体比例为准，检查胸腹、腰臀与腿脚，而不是只加一根细躯干。圆墩孩童应少收腰、腿粗短、站距合适；必要时同步调整斗篷容量。 |
| 三叶草图案在深褶处穿插、出现碎片 | 让图案按布面三角形精确裁分并贴合，保留微小表面偏移；单纯增加均匀细分会浪费面数，也未必消除穿插。 |
| 动作草稿被误当作正式动作组 | 明确标记测试动作、正式制作清单和运行接入状态。两个测试动作能验证绑定，不代表动作制作完成。 |

## 三叶旅童当前方向与边界

当前候选状态见[资产说明](Exports/clover-wayfarer/README.md)，实测数据见[模型报告](Exports/clover-wayfarer/model-report.json)，不把本页写成第二份随版本漂移的参数表。

- 森林孩童low poly；颜色简单，以绿黄、暖木色、奶油色及少量碧绿识别色组成。
- 猫头鹰形木板面具；两个深色眼孔里有碧绿小眼睛，额头有同色三叶草。没有鼻、喙、嘴或实体头球。
- 有躯干、内衫、腰臀和双腿；身体偏圆墩，少收腰；没有双手。无手不应成为删掉身体的理由。
- 长斗篷到脚踝上方，背部没有包或装备；背面有三叶草。帽前沿近额头、后帽顶略高成弧，帽侧和领口有布片叠褶。
- 当前仍是美术候选。已将待机／走／跑／受击／死亡／跳跃六项试绑到模型；见[动作预览与边界](Animations/clover-wayfarer/basic-trial/README.md)。尚未完成布料碰撞或生产场景接入验收。

主参考：[ORICUT · Forest Spirit Nori](https://oricutstudios.itch.io/low-poly-forest-spirit-nori)；辅助风格参考：[Campfire Scout Niko](https://oricutstudios.itch.io/low-poly-campfire-scout-niko)。本轮重新查看的[侧面与线框检查图](Concepts/clover-wayfarer/references/nori-gallery-review.jpg)、[用户面具标线](Concepts/clover-wayfarer/references/user-owl-outline-v03.png)及[来源链接](Concepts/clover-wayfarer/references/sources.json)均已保存。

## 可复用的Blender与导出经验

- 保存可编辑 `.blend`、构建脚本、预览、导出及检查报告；造型阶段的源文件放 `ArtSource/`，按接入流程另行放置运行资源。
- 大改前保留上一版。脚本会重建资产自己的场景，运行前先检查是否有需要保留的人工编辑；保留用户其他场景和编辑器。
- 身体比例改变时，同步处理身体、斗篷容量、脚掌站距、骨架静止位置、蒙皮权重和预览镜头。头部需要保持形状时，可整体下移以配合短身，不必一起压扁。
- 斗篷可用薄布面和必要的窄幅翻边。检查双面显示、布边法线、图案贴合和身体净空；布料观感首先由形体决定，不必先引入实时布料模拟。
- 当前中文Blender的节点名可能本地化，按节点 `type` 寻找 `BSDF_PRINCIPLED`、`BACKGROUND` 等，不依赖英文显示名称。
- Blender MCP安全模式中直接提交脚本源代码；保存、渲染与导出使用Blender操作，不使用 `exec(open(...).read())`。
- GLB只导出角色集合，并同时限定选择对象与当前场景，防止其他场景默认Cube或摄影棚进入资产。脚底原点、朝向和缩放保持明确。
- 检查权重归一化、未绑定顶点、闭合身体体积、衣物穿插和若干待机／走路姿态。真实运行所需的足底、碰撞、事件和镜头效果仍需后续验收。
- 面数、骨数和动画数以实际导出与回读为准。导入器可能创建骨骼显示辅助网格，统计角色几何时应排除；当前样件的数量不是未来模型的固定标准。

## 动画制作接续

项目现有直接使用的基础动作包括待机、走路、跑步、受击、死亡。起跳／下落／落地、转向／急停、冲刺／闪避按角色行为补充；攻击、连段、蓄力、释放和收招按最终武器与技能拆分，不能在角色定位未确定时随意固定整套战斗动作。

斗篷应跟随起步、停步、转向和起落体现拖曳与回摆。快速动作按[美术接入约定](../docs/art-onboarding.md)保留已验证的60fps采样；本资产v09六项试绑已改为60fps。伤害和格挡等仍接真实动画事件，详见[动画管线](../docs/anim-pipeline.md)与[外轮廓表现事件](../docs/motion-fx-authoring.md)。

2026-10-25用户补充：寻找动画参考可选完整人形，**不需要排除包含手部动作的示例**。重点判断动作的重心、节奏和腿脚是否适合当前模型；参考里有手不改变当前角色无手的造型要求。首批[12段基础动作参考与媒体](Animations/References/clover-wayfarer-basics/README.md)已整理，包含原速视频、慢放GIF及作者展示链接，尚未重定向为角色正式动作。

2026-10-25用户筛选后，只先制作**待机／走／跑／受击／死／跳**。慢跑示例像跳跑且身体摆动过大，不采用；跳跃不采用长下蹲蓄力，应短促起跳；击退不能使用击倒动作，可保持普通受击姿态并由运行位移后移。其余特项先放置。v09已据此完成六项试绑和真实模型媒体，仍是候选。成人骨骼重定向到大头短腿角色时，身体世界转动减弱、脚迹缩短并做两骨IK；死亡应核对整身和巨头接地，不能仅按成人脚底校正。

## 后续如何积累

每轮有价值的反馈按“参考图或用户反馈 → 当前差异 → 采用改法 → 对照预览 → 应保留的原则”追加。通用经验写本页，具体造型、参数和版本状态写资产说明。保留失败版本以便比较，但只把用户确认或实际验证过的结论提升为后续依据；未验证的尝试清楚标注。

2026-10-25最新反馈：六项动作当前可以，等待装入游戏后测试。面具虽然需要保留雕刻木板材质和猫头鹰外轮廓，板面不能直板生硬；v10改成中央微鼓、两侧后收的浅球面脸罩，眼孔、眼睛和额头图案同步变形。此要求更新了早期平板面具的表面形体要求，不增加鼻嘴或内部头球；动作关键帧保持原样。
