# 人形产线样件

这是一件验证生成、整理、绑定、动作和导出的试件，造型不使用游戏现有模型作为参考。

- `humanoid-pilot.glb`：带骨骼、贴图和三个测试动作的运行候选。
- `mixamo-upload.fbx`：未绑定的 T 姿势网格，供 Mixamo 网页自动绑定使用。
- `preview.png`：Blender 渲染预览。
- `project.godot`：独立的 Godot 预览项目。打开运行后，按 1／2／3 切换待机、走路、关节检查。
- `validation.json`：本机 Godot 4.7.2 的导入及动画驱动校验结果。

双击 `Start-Preview.cmd` 可用本机已安装的 Godot 直接运行预览。
这个项目独立于游戏主工程，未替换游戏角色，也未接入技能事件和武器挂点。

## 实测结果

生成任务 `1503679606820970496`，混元 3.0／LowPoly，消耗 25 积分。
原始 OBJ 为 4,335 个顶点、3,339 个四边面及 1,988 个三角面，未发现非流形边。
运行 GLB 为 8,666 个三角面；单材质、4K 颜色贴图，约 10.4 MB。
尺寸规范为 1.8 米，脚底原点；Blender 为 Z 向上、朝向 -Y，GLB 转为 Y 向上。

基础骨架共 23 根骨骼，其中 22 根用于变形。使用 Mixamo 风格的主要骨骼名称，
每个顶点最多四个归一化权重，无未绑定顶点。当前手指整体跟随手掌，没有独立手指或面部骨骼。

Godot 已加载 23 根骨骼及三个动作，并验证走路动作会改变骨骼姿态；预览启动无报错。
三个动作只用于验证产线，仍需正式动作制作、足底接触与肩胯权重精修。
Mixamo 上传文件已准备，尚未经过 Mixamo 网页自动绑定和动作下载回测，不能据此宣称线上兼容验收完成。
