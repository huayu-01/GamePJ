# 敌人形象修订：怯生蘑菇与鬼火法师

> 历史提案，已被用户否定。最新要求已取消刻意不对称，蘑菇采用胆小菇模样，法师改为黑圆头与黑色幽灵身体。请以后续[第三版](../2026-10-21-revision-03/README.md)为准；下文仅记录本版当时的探索。

日期：2026-10-21。本轮根据用户更正重新探索 E10、E13 外观。使用内置 image_gen，完整提示词见 [prompts.json](prompts.json)。图片是外观概念，尚未制作对应 3D 模型或动画。

## 共同美术方向

- 简洁几何、卡通大块面、少量主色，保持当前森林美术样板中的辨识度。
- 允许奇特、略带猎奇感的生物设计。参考《雨中冒险 2》刻意设计的不对称感，不以端正、镜像对称的人形为默认模板。
- 不对称主要体现在剪影、体块重心和五官位置；不靠堆叠饰品、细碎纹理增加复杂度。
- 不要求所有敌人两臂两腿，也不为了适配 Mixamo 牺牲已确认的形象。非人形可单独制作简单骨骼、形变或材质动画。

## E10：怯生蘑菇／enemy_burrow_hunter

图稿：`e10-burrow-hunter-v2.png`。

“地鼠”描述遁地换位的行为，不描述动物外形。用户希望接近《植物大战僵尸》胆小菇的怯生蘑菇感觉：大伞盖、短菌柄，紧缩畏缩的姿态。新稿采用偏心下垂的伞盖、弯向一侧的菌柄和错位大小眼，让它古怪而不板正；不沿用初稿鼹鼠的毛发、爪、护目镜或种子枪。

追踪弹可以表现为孢子，保留原有“发射→等待→遁地→有效位置出土→再射击”的行为循环。

缩地动画的后续制作顺序：怯缩收身→菌柄压缩、伞盖贴地→主体沉入地下→地表短暂反馈→新位置先探出伞盖→菌柄伸展复位。伞盖与菌柄可分控制，动画要保留不对称轮廓。该序列当前是制作要求，尚未落为模型、动画资源或游戏接线。

## E13：歪帽鬼火法师／enemy_meteor_mage

图稿：`e13-meteor-mage-v2.png`。

主体是一团戴着法师帽的小鬼火，没有腿脚。实体歪帽与偏向反侧的幽灵尾焰形成错位重心；下半身由大块火焰形逐渐透明淡出，不使用人形短袍和靴子。帽子、火团、尾焰构成主要轮廓，减少饰品与粒子细节。

保留现有蓄力、采样玩家位置、上方落弹的法师行为。后续动作可采用帽子滞后摆动、主体收缩蓄力与尾焰伸展；悬浮是外观表现，当前不增加飞行导航或飞行敌人系统。透明与自发光需要在实际森林光照中检查，避免强泛光抹掉面部与尾焰形状。
