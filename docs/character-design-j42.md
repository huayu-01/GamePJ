# J42 灵剑三剑协同与灵能汲取

按2026-10-21最新要求重做灵剑武技2，覆盖原始设计中的“拔刀式／大拔刀术”。不新增对话，不扩展敌种或精英词条。

## 当前行为

- 武技2暂名“三才灵剑”：右键即时在玩家头顶召唤3柄灵剑，持续10秒，召唤成功即起算15秒冷却。它是背景持续效果，不占用挥剑／闪避动作；持续期间不叠组，续时超过冷却时仍需等本组消失再召唤。
- 当前近战连招的真实ATK发布攻击快照，3柄灵剑沿握持武器骨骼挂点的空间姿态在外圈挥击，水平方向扩大距离，剑尖高度保持原路径。五段动画分别验证；不根据固定段号猜测挥砍方向。
- 原挥击结束或被打断，关闭剑体伤害并缓慢归位。三剑全部归位后才允许下一次协同；归位期发生的攻击不排队补发。没有ATK时不计时补发。
- “灵能汲取”替换“大拔刀术”：玩家本人真实击杀敌对单位时，当前灵剑持续时间增加2秒。不限击杀技能；没有灵剑或已到期时不储存续时、不复活。奖励获取不修改伤害／范围；保留`evo_great_draw`及原池引用，技能保持`skl_b1_w1_2`。
- 换武器／重新配装、禁用、玩家死亡和退树清理剑体、伤害、订阅与续时状态。HUD分别显示冷却和当前灵剑剩余秒数。

## 可调预设与接入

用户明确的10秒／15秒／2秒来自技能和奖励资源；未指定的单剑伤害暂取本段近战快照的30%，三个外圈中心为3.4／4.05／4.7米，归位1.1秒。三个剑体各自每段每目标至多一次，待机／归位不造成伤害，基础伤害、连招段、暴击率与暴伤继承该次近战快照，玩家攻击力不重复相乘。外圈跟随近战范围属性，归位目标随玩家移动与转身更新。

`SpiritSwordsAbility`通过`MeleeComboAbility.StrikeStarted`监听真实出手，通过真实握持剑变换更新独立`AttackHitbox`并做分段扫掠。召唤本身无需角色施法动画；协同攻击仍依赖近战真实动画事件。灵剑沿用统一阵营／格挡／护甲／伤害结算，额外剑体不重复触发施法者顿帧。持续时间和冷却随游戏时间，挥击及归位跟随玩家局部命中停顿。

技能参数在`Config/Tables/Skills/skl_b1_w1_2.tres`，灵能汲取的2秒在`SkillEnhancementTuning.KillExtensionSeconds`。说明模板直接引用该资源字段，不额外复制一份显示数值。灵剑使用独立蓝白发光剑体与金色剑格，现为机制表现原型，最终模型／拖尾／音效仍可在美术阶段细化。
