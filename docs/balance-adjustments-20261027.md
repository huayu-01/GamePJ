# 数值调整与确认规则 · 2026-10-27

本轮按玩家对平衡评审的反馈实施。目标是保留困境中成长、成型后进入收割与低压阶段的体验；飞刀贴脸吃满多弹属于极端场景，不据此削弱。前一份平衡评审保留为调整前的分析基线，其中未采纳的削弱候选不作为执行计划。

| 项目 | 调整前 | 本轮生效 |
|---|---|---|
| 行军符文 | 移速×2（+100%） | 移速×1.75（+75%） |
| 巨人符文 | 每命中额外造成最大生命10%伤害 | 比例降至8%，命中与联动规则保留 |
| 精英额外护甲 | 固定+120 | `max(120, 最终最大生命×30%)`，原型自带护甲另加 |
| 地鼠追踪弹 | 6.6米/秒 | 13.2米/秒 |
| 远程投掷抛射 | 飞行1.6666667秒 | 1.1666667秒，缩至70% |
| 投掷抛弹 | 飞行1.8333333秒 | 1.2833333秒，缩至70% |

“小幅削弱”以保留符文优势为准：行军实际移速相对原值下降12.5%，巨人的附伤部分下降20%。符文说明和中文本地化改为读取数值，避免说明与配置不同步。

护甲范围已经再次确认：只改精英额外护甲，玩家护甲增幅、死铠、重铸及角色/敌人的基础护甲仍按原规则。精英护甲按全局倍率、主线区域/死战阶段、巨壮等出生特性全部生效后的最大生命计算。例如无基础甲的1125生命重型精英获得337.5甲；低生命精英仍至少获得120甲。

比例护甲是初始化来源，不是每帧恢复机制。普通属性刷新及战斗中单独改变最大生命不会自动补回损失的护甲；出生/显式回满时按最终生命重新计算，重复回满不重复累加。技能护卫原本用精英组件提供身份/外观、另有基础甲，此类组件明确不重复授予随机精英护甲。

抛射直接缩短飞行时间并重新解算初速度，沿用原重力、射程、伤害和前摇。实际发射与预警共用该解算。追踪弹保留原转向率和20米航程；未同步提高控制或伤害。普通直射、陨石、前射炸弹和玩家弹体不跟随这次修改。

不执行前份评审中的后期叠场、回血、重复力量/移速、精英费用、首领血量等额外收敛建议；构筑成型后强于初期是本项目明确接受的体验方向。
