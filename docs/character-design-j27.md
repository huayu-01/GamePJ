# J27：飞翼下落攻击加速（2026-10-18）

补全后续构筑原文“飞翼：跳跃高度更高，提高上升速度，降低正常下落速度，下落攻击的下落速度更快”。旧飞翼只接起跳与正常下落倍率，真实带符文后三把B武器的下冲仍为34m/s。

`Unit.SeedStats`新增默认1的`DiveSpeedMultiplier`，`FallAttackAbility.EffectiveDiveSpeed`将技能原DiveSpeed乘单位倍率。在真实动画Action处读取一次并冻结完整速度矢量，保留长枪准星方向及垂直分量；后续移除符文不重算已经开始的下冲。默认无修饰器仍34m/s，正常下落夹速继续独立读取MaxFallSpeedMultiplier。速度仍进入原有高度／垂直速度伤害公式及原2倍上限，未添加另一个伤害乘区。

后续直接改`Config/Tables/Runes/rune_flying_wing.tres`的三个Modifiers.Value：

| Stat | 当前预设 | 作用 |
|---|---|---|
| JumpVelocityMultiplier | 1.3 | 起跳速度，沿用J11 |
| MaxFallSpeedMultiplier | 0.8 | 正常下落速度上限，沿用J11 |
| DiveSpeedMultiplier | 1.3 | 下落攻击整条速度矢量，本批补全 |

原文没有给倍率，1.3是可调预设，平衡后置。说明共读三个修饰器，改表时同步；旧说明把起跳速度+30%等同跳跃高度+30%也已改为准确的速度倍率。复用原StatSet，不新增符文处理器、表行或ConfigIndex引用，奖励仍70=17/23/30、符文11。
