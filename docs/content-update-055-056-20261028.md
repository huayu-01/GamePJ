# 055／056：能量波空间波与弹窗防误触

## 055：爆裂火球的命中表现

能量波的爆裂火球使用独立的 `EnergyPulseExplosion.tscn`。半透明淡蓝外壳在0.48秒内扩张、产生轻微背景折射与波纹，随后消退。一个网格，不添加爆炸灯光或火烟粒子；最大视觉半径为实际爆炸半径的90%，去掉旧火烟表现的2.5倍附加放大。

`Projectile.ExplosionScene` 是可配置的可选预制体引用。能量波场景指定新资源，其它弹体留空，继续使用原爆炸场景。没有按技能名称或角色名称分支。折射强度与颜色在 `Assets/Effects/energy_pulse.gdshader`，时长及视觉比例在 `Scripts/Combat/EnergyPulseFx.cs` 的导出属性中调整。

伤害仍走同一个 `Explosion`：爆裂火球保持3.5米／60%伤害，判定窗口仍为0.12秒。表现取得最终世界位置和缩放后脱离短命的判定体，独立播放并回收；不更改伤害、冷却、目标规则或判定时长。每个实例复制自己的表现材质，避免同时命中时相互覆盖进度。

## 056：一秒保护及旧输入松手隔离

共用 `OverlayScreen` 默认打开淡入／缩放1秒，输入保护至少覆盖打开动画。关闭保留0.16秒。若配置更长的打开动画或保护时间，按较长值保护；打开动画设为0也仍保留默认1秒输入保护。

`UiOpeningGuard` 使用真实时钟，不受游戏暂停影响。保护期内的鼠标、键盘、确认动作和手柄按钮在GUI处理前被消费。开窗时或保护期内按住的左键、Enter、Space、选择数字键及 `ui_accept` 必须先松开，旧松手本身也不会领取；松开后新的点击／按键才能确认。因此持续按左键输出不会在保护结束后凭旧输入选中奖励。

每次打开都重置保护，包括连续奖励。只拦截有效顶层，保留暂停、叠层和单次发奖规则；设置面板的按键重绑先经过基类过滤。独立的死亡结算也共用这套保护，演出跳过和结算确认不能连在同一次输入里。
