# J25：践踏死亡逐杀计数与空中立即补回（2026-10-18）

原文要求每次击杀获得额外跳跃次数，上限N。用户进一步确认：**空中击杀立即可用，最大容量达到上限后仍可补回已消耗次数**。每杀1／上限3沿用现有可配预设，不做平衡调整。

- `KillAirJumpRule`只记录拥有者的Kill事实，自行在Ready／ExitTree成对订阅和退订。纯计数不生成攻击、不广播事件，独立于通用攻击连锁的冷却、每链四次和深度门；通用`TriggerRule`及其他攻击规则保持。
- 新`CharacterMovement.GrantAirJumps(amount, cap)`原子增加未满的最大容量与立即可用次数，满容量后仍可按每杀增量补回，两个量都遵守此效果上限，不减少其他来源已拥有的次数。原`SetExtraAirJumps`继续负责被动／配装的幂等容量设置，不能让每帧被动回填已消耗次数。
- `mut_stomp_kill`迁`KillAirJumps`处理器，删除旧Trigger／0.1秒Cooldown；`ExtraAirJumps`与`JumpCap`仍在HandlerParams，说明共读这两个值。A灵动的1次保留并逐杀叠加；B无被动从0累加。无增幅、他人击杀、非致死命中和卸除规则后均不误授予。
- 真实一刀同帧三杀逐个计入，封顶后可真实使用三次空中跳；空中用尽后击杀立刻补1，真实跳键立刻能用，再次多杀封顶、部分剩余只加增量、不直接回满。复制真表改每杀2／上限5后，容量和可用次数都实际采用新值。
- Main同步Matches／Execute参数与一次增量检查迁新规则类型，保留原匹配／伤害相关断言；真实多杀和空中回填由新专项验证，不把Main同步入口称作完整端到端。
