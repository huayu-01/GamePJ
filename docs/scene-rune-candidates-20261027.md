# 场景符文候选清单

对应验收033。本文是候选设计，本轮不实现这些候选，也不加入当前随机池。所有数值为可调整预设。首版8枚已接入符文仍见 `scene-runes-20261027.md`。

每场只安装一种场景符文，顶部UI显示图标、名称及完整说明。同种符文可以周期触发；不因此叠加第二种机制。下面每行是完整的一枚符文，“灵魂盛宴”的增怪与灵魂掉落属于同一个组合效果。

| 名称 | 候选效果 | 互动与实施边界 |
| --- | --- | --- |
| 灵魂盛宴 | 敌人产出数量提高20%；自然生成的敌人死亡有5%概率掉落灵魂，拾取恢复5生命。 | 额外生成仍受人数、压力、待生成与实例上限约束；灵魂只结算一次，召唤随从不掉落，死亡连锁不重复掷骰。 |
| 武装 | 敌人生命首次低于50%时获得最大生命5%的护甲，上限200。 | 每单位每场一次；治疗后再次过半血不刷新，破甲后不再自动补回。该甲与精英出生甲分开记录。 |
| 天雷滚滚 | 每8秒在随机可达位置预告，1秒后落雷，对半径2.5米内所有单位造成25环境伤害。 | 预警颜色明确表示敌我均受伤；不归属玩家主动攻击，不递归触发命中增幅。 |
| 顺风回廊 | 周期出现固定方向的风带，顺风移动加速25%，逆风减速15%，敌我均受影响。 | 限定地面接触；离开立即撤销，不直接覆盖角色速度；不推入不可达地形。 |
| 温床 | 每18秒生成一块持续8秒的暖地板，站立每秒回4生命，但攻击速度降低15%，敌我均适用。 | 治疗受单位自身禁疗/倍率约束；离开撤销减速，鼓励玩家引走敌人再回血。 |
| 晶壳 | 周期生成一枚可击碎的晶体，击碎后掉落一份临时护盾，持续6秒。 | 不掉普通奖励，不算敌人击杀；晶体和拾取物各有数量上限，不能重复领取。 |
| 回响足迹 | 玩家移动时每隔2秒在原位置留下印记，0.8秒后爆发，只伤敌人。 | 强调持续移动；使用延迟采样位置，不追着当前玩家爆炸。 |
| 熔地脉冲 | 每12秒铺出两条有间隙的地面热带，预告后持续3秒伤害所有接地单位。 | 可跳跃躲避；实际伤害几何与预警一致，连续跳伤有间隔。 |
| 月相 | 每30秒交替10秒“清辉”和20秒“暗面”：清辉期间玩家拾取范围+30%，暗面恢复正常。 | HUD显示当前月相；只是当前符文的阶段，不重抽场景符文。 |
| 追逐火种 | 一枚火种沿导航地面缓慢移动，靠近后玩家获得持续3秒的移速+20%。 | 只有一个火种，不能出现在孤立屋顶或障碍内部；增益刷新时长、不重复乘算。 |
| 共振石 | 场中出现可敲击石柱，击中后0.7秒发出一圈冲击波，伤害并击退敌人。 | 石柱不能锁死道路；每柱有触发冷却，玩家攻击自身产生的波不再次触发石柱。 |
| 窃光 | 周期生成明亮区域，玩家进入获得伤害+20%，区域外恢复原值。 | 采用明确可见的地面边界；与现有力场区别在于区域会缓慢移动，第一版不建议同时制作两者。 |
| 逆流 | 每20秒产生一枚缓慢横穿战场的水球，接触推开单位并熄灭其燃烧。 | 不作为格挡/招架；推力有上限，不能把首领推离战斗边界。 |
| 星屑回收 | 自然敌人掉落经验有10%概率变为一颗额外大经验球。 | 按掉落收据一次掷骰，保留总经验明细，避免视觉合并导致重复结算。 |
| 战地补给 | 每45秒出现一个只能领取一次的补给点，持续15秒；接触恢复最大生命10%。 | 场上最多一个，过期回收；不进入普通奖励池，不暂停战斗。 |
| 岩脉震荡 | 每15秒地面短暂预警后震动，接地敌人受到伤害和短击退，空中单位不受影响。 | 可用跳跃避开自身移动干扰；不能复用全屏镜头抖动代替判定，镜头强度遵守玩家设置。 |

建议下一批先选灵魂盛宴、武装、天雷滚滚和回响足迹：分别验证掉落、单位生命周期、敌我环境伤害及位置延迟四类扩展。其余保持候选，不预先接入运行期。

独立护甲节点已列入032。以后死战可以另设计“恢复／护甲／一次格挡／临时增益”的生存选项，它与场景符文属于不同获取系统，本轮不提前实现这组选项。
