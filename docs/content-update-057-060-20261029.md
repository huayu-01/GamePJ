# 057～060：跳字跟随、独立掉落、后撤与招架反馈

## 057：伤害数字随目标投影

原实现只在命中时投影一次，再用Tween直接改变屏幕坐标；相机转动后数字会停留在旧屏幕位置。现在使用短命的 `DamageNumberLabel`，逐显示帧按目标世界位置重新投影，上飘仅影响相对于投影点的局部偏移。它在相机更新后排布，不改变跳字数值、颜色与分类错位。

目标移动时继续跟随；目标释放后保存最后世界位置，继续随镜头投影并淡出；位置在镜头背后则隐藏，时长结束回收。玩家恢复数字也传入玩家锚点，避免只有伤害数字修正而恢复仍漂移。

## 058：经验与灵魂同时掉落并摊开

现有死亡经验回调与灵魂收割的Kill订阅本来独立，没有发现只能掉一种的互斥分支；本轮真实授予增幅后击杀，没有复现经验掉落停止。两类拾取物原本都生成在死者原点，大灵魂容易遮住小经验球，近身经验还会立即进入吸附过程。

新增共享 `PickupDropLayout.Claim(victim, origin)`，只负责为同次死亡的不同掉落来源分配落点，不决定概率与种类。首个掉落保留中心，其后以0.8米间隔寻找相邻地面位置，检查已占落点；狭窄位置找不到空位时保留有效原点。记录存在死者运行期元数据中，随死者回收，不建立全局逐帧掉落扫描。

死战经验与灵魂分别调用该接口；未来护甲球等成功掷点后可直接领取另一个位置。经验数值、灵魂的原概率／恢复值与拾取规则不变。满容量经验仍按原方式合并数值。本轮未新增护甲球奖励。

验证覆盖：无灵魂收割、真实授予后必掉、概率未命中、同一死者重复伤害不重复发放、同次死亡的两种落点间距、第三来源可领取空位，以及实际拾取后经验入账和灵魂恢复生命。

## 059：6米后撤在0.5秒内完成

原配置是20m/s冲量，随后每物理帧按阻尼6衰减。在60Hz、无输入无碰撞的对照中总位移约3米；新默认距离翻倍为6米，真实Dodge事件后以0.5秒完成。`BackwardDistance` 与 `TravelSeconds` 在角色A的后撤技能行Params中配置。

`CharacterMovement.BeginVelocityOverride` 新增可选 `planarOnly` 参数，默认关闭，已有三维下冲调用保持原语义。后撤仅覆盖水平速度，重力与外力仍参与垂直速度，实际移动继续走MoveAndSlide，可被地形阻挡；不会通过改坐标穿墙。空地对照、墙体阻挡、空中重力及取消／换装释放均有回归。

保留起手朝向。无敌仍由原Dodge／Dodger事件开关，不把整段位移自动扩展为无敌；原动画早于位移结束时，关闭无敌后等待位移结束再收招，取消或换装则立即释放。源动画和事件帧没有重做。`BackwardDistance=0` 可恢复旧冲量兼容模式；弓的免费后撤复用同一技能。

## 060：真实成功招架的专用反馈

成功招架增强为身体前方的金色扩张冲击环与8束火花，默认0.3秒；叠加原身体边缘闪光、格挡音效与短促镜头反馈。`CombatFeedbackProfile` 的 `ParryBurstSeconds`、`ParryWeight` 与 `ParryPitch` 是独立调参入口。音效仍使用项目已有CC0命中采样，以独立较亮音高区分招架，后续可在原 `BlockSound` 配置更换专用录音。

远程反射发生在普通ReceiveHit之前，原来会跳过结算后的反馈路由。现在真实招架事实发生时请求共用反馈，同一HitInstance标记已经表现，防止近战随后经过ReceiveHit时重复。持续招架窗口与反弹伤害规则不变；未成功格挡、一次性效果护罩以及窗口外普通受击不冒充招架。

效果没有碰撞或伤害，正常深度绘制，受全局特效数量与音效节流约束；持续招架不会按帧重复生成光效。
