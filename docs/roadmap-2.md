## 3. 第 12 条：碰撞层级的现状与建议（用户直接问的）

### 3.1 现状

**✅ 好的一面：代码层已经有语义化封装**

```csharp
// Scripts/Combat/Unit.cs:138-140
CollisionLayer = CombatLayers.Of(Faction);
CollisionMask  = Faction == Faction.Player
    ? CombatLayers.World | CombatLayers.UnitMask
    : ...;
```

→ 说明**层语义是有的**（`CombatLayers.World` / `UnitMask` / `Of(Faction)`）。

**❌ 问题一：`project.godot` 里没有 `[layer_names]`**

侦察确认：`project.godot` **没有 `[layer_names]` 段** → 编辑器里看到的全是裸数字：

| 数字 | 语义 | 出现次数 |
|---|---|---|
| `6` | `2 \| 4` = Player + Enemy（**`UnitMask`**） | **16 次**（都是 `.tscn` 里的攻击盒） |
| `1` | World | 2 次 |
| `2 \| 4` | 同 `6`（C# 里写成 `CombatLayers.UnitMask`） | 1 次 |
| `0` | 不参与碰撞（攻击盒的 `layer`） | 16 次 |

**✅ 一个做对了的模式**：**攻击盒一律 `collision_layer = 0`（自己不参与碰撞）+ `collision_mask = 6`（只检测）** —— 这是**正确**的（"谁检测谁"用 mask，"我是谁"用 layer）。

**❌ 问题二：层太少（只有 3 层）**

World / Player / Enemy 三层，**把"物理碰撞"和"战斗判定"混在一起**了。

**❌ 问题三：玩家/敌人的物理层包含对方单位**

```csharp
CollisionMask = Faction == Player ? World | UnitMask : ...   // ← 含 UnitMask
```
→ **玩家会跟敌人在物理上互撞** → 这与近战「冲刺穿透」（角色 B 技能1「闪」：**全程穿透但无法穿透地形**）和「剑突穿过敌人」直接冲突（P0 调研就记过这条）。

### 3.2 建议（按风险从低到高）

#### ① 立刻做（零风险，纯收益）：给层命名

在 `project.godot` 加：

```ini
[layer_names]

3d_physics/layer_1="World"
3d_physics/layer_2="PlayerUnit"
3d_physics/layer_3="EnemyUnit"
```

✅ **编辑器里从此可读**（不再看到裸 `6`）· ✅ **不改任何行为**（只影响显示）· ✅ **风险 = 0**

#### ② 顺手做：把"层的语义"写进 `docs/architecture.md`

因为 `.tscn` **只能写数字**（Godot 场景格式限制），所以**代码/文档要承担"数字 ↔ 语义"的对照**。
（`CombatLayers` 类已经在承担一半；补文档即可。）

#### ③ 中期（建议做，但要一轮完整回归）：**分离"物理碰撞"与"战斗判定"**

**新增层**（建议）：

| 层 | 名字 | 用途 |
|---|---|---|
| 1 | `World` | 地形/墙 |
| 2 | `PlayerUnit` | 玩家单位的**物理**体 |
| 3 | `EnemyUnit` | 敌人单位的**物理**体 |
| 4 | `PlayerHitbox` | 玩家攻击判定（`Area3D`） |
| 5 | `EnemyHitbox` | 敌人攻击判定 |
| 6 | `Projectile` | 子弹/投射物 |
| 7 | `Interactable` | 交互物（门/终端/角色对象） |
| 8 | `Pickup` | 掉落物（第 4 条/灵魂收割要用） |
| 9 | `VfxOnly` | **纯视觉**（残影等，**不参与任何碰撞** —— P6c 的残影是"做减法"实现的，有了这一层可以更省事） |

**核心原则**：
- **`layer` = "我是什么"**，**`mask` = "我检测什么"** —— 两者不要混用
- **攻击盒/hitbox**：`layer = 0`（或专用 hitbox 层）+ `mask = 敌对方单位层`
- **投射物**：`layer = Projectile` + `mask = World | 敌对方单位`
- **纯视觉**（残影/特效）：**不进任何层**（或 `VfxOnly`）

#### ④ 最关键的一条：**玩家/敌人的物理层不该包含对方单位**

**现状**：玩家 `CollisionMask = World | UnitMask` → **玩家和敌人在物理上互撞**。

**建议**：
- **单位物理层 = `World` + 同阵营单位**（即：自己和队友互撞是合理的，**但和敌人不互撞**）
- **"和敌人交叠"由战斗判定（hitbox/projectile）负责**
- ⚠️ **这样改完，近战的"贴身"手感会变**（能站进敌人身体里）→ **需要配套**：
  - **近战命中判定**要够大（不能靠"物理挡住所以刚好在攻击范围内"）
  - **或者**：保留"轻微推力"（`CharacterBody3D` 的 `move_and_slide` + 敌方层只在移动时检测、不阻挡？**Godot 没这个区分**）→ **更实际的做法是"敌我互不阻挡，但加一个软推挤"**
- ⚠️ **风险**：**影响全部单位/敌人/AI 寻路** → **必须单独一轮 + 全量回归**

#### ⑤ 长期：物理与战斗彻底分离

**物理**（`CharacterBody3D`）：只跟 `World` 交互（撞墙/落地）。
**战斗**（`Area3D`）：独立层，互不干扰。

**收益**：近战穿透/冲刺/闪避的手感问题**从根上解决**。
**代价**：一次性大改 + 回归。
