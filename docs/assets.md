# 当前资源规范

本页说明运行资源的目录、引用和替换约定；制作流程见[美术接入](art-onboarding.md)，资源去留依据见[生命周期审计](resource-lifecycle-audit.md)。

- `Assets/` 保存运行模型、材质、动画、图标、音效与许可；`ArtSource/` 保存概念图、生成原件、Blender主工程和导出候选，其 `.gdignore` 隔离制作源。
- `Scenes/` 保存组装后的角色、敌人、武器、环境与交互预制体；数值和强类型参数放 `Config/`。
- 原始许可、来源、哈希、可编辑源文件与导出参数属于资产的一部分；不能因不进入主场景而清理。
- 命名采用稳定英文标识。资源改名必须同时检查路径、UID、稳定Id、目录扫描和插值命名，不能只依赖直接引用次数。
- 正式交互物统一由 `InteractionModel` 按组件类型生成新几何，编辑器与运行时共用；制作入口见[交互组件](interaction-authoring.md)。旧 `mesh_node_<kind>.tres` 与 `mat_node_<kind>.tres` 仍供Main／历史专项使用，不再是正式基地／森林的外观调参入口；旧圆柱节点资源已移除。
- `Scenes/Weapons/Pistol.tscn` 是当前六武器共用组件壳，保留旧名兼容；它不是可选旧手枪内容。
- 表现只读战斗事实。模型缩放不能默默扩大命中几何，替换骨架必须同步握持骨骼和技能动画库。
- 每个实例通过 override 或私有副本改变材质／动画，避免修改共享资源导致全场串色或事件漂移。
- `.uid` 和 `.import` 可能决定稳定引用、60fps动作采样及材质导入，不能批量删除。

资源替换至少检查：加载、真实游戏镜头、动作事件、碰撞与导航体型、甲壳／闪色／预警、换装与死亡清理。现有资源清单、旧命名示例和接入历史已[完整归档](archive/reference-before-2026-10-21/assets.md)。
