# J47：正式交互物全部替换为类型模型

2026-10-22。用户明确要求不保留原模型，本轮替换正式基地与森林中的交互外观；统一由 `InteractionComponent.Kind` 决定行为与新造型，编辑器选类型即可预览。制作入口见[交互组件手册](../../interaction-authoring.md)，上一轮兼容原模型的方案留在[J46历史记录](character-design-j46.md)，不再作为当前制作约定。工作区尚未提交推送。

## 替换范围

- 基地六个交互物：出击、能力矩阵、帮助、两角色展台、符文台。移除旧台体网格、材质和展台预制体引用，使用普通宿主与组件；角色间距、布局及业务保持。角色人物和握持武器继续从生产配置读取，新展台重新创建展示子树。
- 森林十个奖励节点、首领门及首领后的动态出口。旧奖励／门预制体实例替换为普通宿主与组件；保留类型映射与节点位置，10节点和高2／中5／低3规则保持。换关回收动态出口整个宿主，不留下新模型空壳。
- 示例场景移除旧方块与棱柱，改为自动类型模型；仍保留真实Area和说明标签。
- 新 `InteractionModel` 为16种有效类型建立不同几何：叠层、箭头、异化尖刺、资源堆、恢复十字、特殊星形、商店箱、首领门、离场环、出击门、能力卡、交叉武器、符文环、问号、角色台座与机关。共用底座结构，奖励价值环仍读取ValueTags，不把颜色当作类型形状差异。

组件不再导出 `HighlightMesh`／`HideOnUse`，只读 `ModelRoot` 供代码检查。迁移宿主携带的旧模型会隐藏，禁用、使用、消失与Reset只控制新模型。宿主自身是Mesh时仅令旧几何透明，保留其父树可见性，不连带隐藏新模型；独立交互子物体、触发器、碰撞与说明标签不受替换扫描影响。

编辑器预览不创建交互后端、不参与收益／配装业务，也不写入场景；切换Kind更新几何并释放旧预览，None撤销预览。实际业务仍在开局读取配置，运行中改类型须停止重跑。
