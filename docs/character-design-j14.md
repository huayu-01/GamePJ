# J14：怜悯与普渡的末刀链路（2026-10-18）

原文：怜悯只释放镰刀武技1最后一刀且该刀伤害增加50%；普渡仅这把武器武技1最后一刀击杀时恢复N生命。本批不包含喜爱，下一项从喜爱继续。

## 实现与真实读数

- **怜悯**：`evo_mercy` 改用强类型 `SkillEnhancement`，目标为 `skl_b2_w1_1`，`ComboStepIndex=-1` 表示当前连招表末段；只调用原末段动画、形状与ATK，单次施法不推进其他段。伤害倍率1.5只在该技能快照消费。真实末刀 **49.4→74.1**，前后两靶都被原360度圆柱判定命中；玩家全局伤害乘区不变。打断、连点不重复、下一次施法仍末刀、重新配装恢复普通首段均实测。
- **攻击快照**：`AttackInstance.ComboStep/ComboStepCount` 在真实ATK生成时冻结。额外近战投射物继承同一段信息；`Unit.Die` 把快照段号／总段数带入真实Kill事件，事件消费者不读角色当前段号。默认总段数0的普通攻击不算末段。
- **普渡**：`evo_salvation` 限定 `RequiredEventAbility=skl_b2_w1_1`，`RequireFinalComboStep=true`；`TablePulseRule` 在Matches阶段检查来源单位、技能与冻结末段。前两刀实际击杀均 **+0**；同一末刀双杀 **195→211（每个+8）**；怜悯与普渡一起获得时，跳到末刀的击杀仍 **+8**。
- **延迟与负例**：把真实第一刀的攻击快照交给实际飞行弹体，延迟击杀时角色已到第3段，仍不回血；实际伤害结算中的武技2来源、其他单位来源、缺少连招快照均不触发。没有直接调用规则Execute冒充真实接入。

N仍是**可配置预设8**（原文未给数）。删除旧预设0.2秒额外触发冷却：原文没有这一限制，每个末刀击杀各回N，同帧群杀不被吞。链深与每链次数保护仍沿用TriggerRule，未移除。

默认不配单段模式时近战仍按原表循环；新字段默认不限定其他事件规则。未增删表行，ConfigIndex的引用／数组／load_steps不改，14个索引数与末尾符文11保持。
