## 统一美术语言

| 观察项 | 本版建议 | 制作时具体检查 |
|---|---|---|
| 整体气质 | 魔幻丛林中的木偶、果实、菌类、幽灵与岩石精怪；明显采用宽叶、藤蔓、根须、树皮、果壳和苔石等熟悉的丛林元素 | 元素参与头、披肩、肢体、盾与脚的形体和材质；正常镜头先读出轮廓，不堆碎小挂件 |
| 比例 | 小型人形采用大头、短躯干、短粗腿和实在的脚掌；非人形按各自结构设计 | 不把成人比例单纯缩小；不让所有物种硬套同一头身比 |
| 轮廓 | 每只保留一个主要识别形：盾、角、菌盖、鸣腔、长刃或重拳 | 缩成黑色剪影时，同场相近敌人仍能分辨 |
| 对称与变化 | 基本形体稳定、接近对称，布褶和石块有自然变化 | 不恢复已否定的偏心大头、错位大小眼与刻意畸变 |
| 几何 | 用少量准确的面表达体积，保留浅弧面、必要倒角与真实厚度 | 避免纯盒子拼装的生硬感，也避免密碎面和随机裂纹 |
| 色彩 | 新造型以2—3个大色区为主，加1个小面积识别色；每色少量明暗变化 | 色数是视觉目标，不能把材质槽数量当成配色质量；已有确认配色保留 |
| 动画上色 | 清楚的亮面／有色阴影，少量宽而浅的涂抹变化；细轮廓 | 不靠密集笔触、PBR噪声或粗黑线增加细节；黑灰敌人也需读得出体块 |
| 木／布／石 | 木表现切面与厚度；布表现悬挂与自由边；石表现体块拼接 | 同样低面数，也不能都像塑料壳或积木 |
| 识别元素 | 三叶草优先保留为主角识别；敌人可用独立眼色和简单符号 | 不把主角图案、无手要求和长斗篷长度强加给全部敌人 |
| 发光与预警 | 常态保留实色，攻击提示短暂出现；沿用共通预警约定 | 不在文字方案里把常亮装饰误写成新的技能机制；与地面危险提示分工 |
| 敌我区分 | 主角的黄绿斗篷与碧绿三叶草继续醒目；新敌多用枯木、灰蓝、莓紫、土橙等辅助色 | 不只靠红绿差别识别敌我；森林绿色背景下还需足够明度与剪影差异 |

上色保留明亮环境下的干净观感。深色幽灵与黑灰石人是已有明确要求，不为追求“明亮”整体染浅。布料是否像布，首先取决于形体和褶皱关系，不能只换一个材质就算解决。

## 各敌人描述与需要重点拆解的细节

下列尺寸均是**外观相对比例提案**，以主角可见高度H作比较，不是碰撞体、伤害范围或生产缩放参数。四足体、菌类与幽灵的可见高度不等于其身体总长。每个方案都需要后续概念图与多视图校正。

### E01 基础近战 · 已选B果壳小卒

- **A的形象：** 约0.85—0.95H，一块方中带圆的木墩作头，头宽略大于肩宽；短圆躯干、粗枝短臂和扁厚根脚。脸只留两个深眼窝与小面积浅黄眼睛。棕木、灰褐身、米色切面三块即可，无背包、盔甲堆叠和复杂纹样。
- **动作与细节：** 待机有轻微身体呼吸，挥击前上体转向蓄力，命中后明确收回。拆头的浅鼓曲面、端面厚度、肩臂连接、根脚接地与手臂摆动净空；不是一根圆柱粘四根棍。
- **B的变化：** 改为栗壳圆头与短布身，保留普通兵的中等体量和短粗比例。选择的是材质与轮廓方向，不额外加投射能力。
- **2026-10-26首图拆解：** 宽圆栗壳头约占可见高度的四成到一半，头壳具有包覆厚度和浅鼓的正面，露出一块浅木米色脸区与小眼窝；以宽叶领／短叶披肩、简洁灰绿短布身和短粗木根手脚强化丛林身份。叶有中折、叠压、自由边，布有悬挂和轻微垂褶，栗壳保留大切面；根脚稳实。色区以栗棕、灰绿、米色为主，双眼少量暖黄；无武器、背包、三叶草或猫头鹰尖耳。首图为单只全身三分之四视角，先看整体造型，不把猜测的多视图当成已定稿设计。

### E02 荆叶快客 · 快速近战

- **A的形象：** 约0.8—0.9H，木核小脸、两三片集中向后收的叶冠，胸腹比E01窄，短腿仍有体积；前臂末端形成简短枝爪。灰绿叶、深棕身、少量淡橙眼色，避免和主角的黄绿长斗篷混成同一轮廓。
- **动作与细节：** 走跑前倾、步频更快，攻击紧凑，少做大幅蹦跳。拆叶片的厚薄与折面、头和颈的衔接、前倾重心、腿的弯折，以及枝爪在正常镜头是否看得见；不靠密密麻麻小刺表达“快”。
- **B的变化：** 换成灰紫短尖帽和收束的短披肩，头身保持紧凑；帽沿、侧布角和领围需要分别成形，不做一只缩小版小法师。

### E03 栗壳跳豆 · 跳跃近战

- **A的形象：** 约0.75—0.9H，圆栗壳头连着短圆腹，两条折叠感明显的粗腿撑在身侧下方，脚掌宽。暖栗棕、浅米与暗褐，壳面只有一两道大分区，不放针刺。
- **动作与细节：** 用可压缩姿态和粗腿读出跳跃，空中团身，真正落地后才有落地攻击反馈。拆髋膝折线、腹腿之间的负空间、脚掌受力、壳体上下层关系。只做跳跃接近，不加入E15的滞空锁向俯冲。
- **B的变化：** 低矮石苔小蛙，头宽、背扁、后腿粗；仍保持大块面。石蛙只是物种备选，不能先改掉当前落地判定。

### E04 钝角木墩兽 · 直线冲锋

- **A的形象：** 高约0.8—1H，身体短而厚、接近横放木墩，四条短根腿；前额一块低矮厚木甲与单个钝角组成前方楔形。木棕、灰蓝额甲、米色角尖，侧面不做细长尖刺。
- **动作与细节：** 起手压低头、撑住后腿，方向锁定后直冲，结束明显刹住。拆额头与角的融合、肩胸宽厚、角与碰撞方向关系、四足站距；不能用细长装饰角代替冲撞质量。
- **B的变化：** 整体换为石楔冲撞体，块石拼接、无武器，前部更宽。它与E16仍应有低矮四足／高大双足的明确区别。

### E05 栗帽吹箭手 · 普通远程

- **A的形象：** 约0.85—0.95H，栗帽宽头、短米灰围领、结实短腿；双短臂在胸前托一根细木吹筒，筒长适度，不做巨炮。土棕、灰蓝布与奶白切面，眼睛仅小面积浅黄。
- **动作与细节：** 直射前吹筒朝准，肩胸轻收，再给短促发射反应；后撤仍能看清枪口朝向。拆帽与头的包覆、吹筒真实厚度、托持接触与身体间隙，避免模型明明朝前、发射口却指侧边。
- **B的变化：** 竖向种荚脸与胸前短口，无外持吹筒，靠种荚体态区别胆小菇；保留直射定位，不使用E10的菌盖和长菌柄。

### E06 铃冠鸣灵 · 尖啸者

- **A的形象：** 约1—1.1H，头罩像厚边小钟，正面一处宽暗鸣腔；两只小眼在鸣腔上方，躯干以几片短垂布收成窄尾。灰紫外罩、深暗内腔、淡米边缘，少量玫红作为动作亮色候选。
- **动作与细节：** 蓄势时向内收、鸣叫时上体展开，强调由内向外的体积变化。拆罩沿厚度、腔口内壁、脸与腔口关系、垂布松弛和尾部弧线；不能只贴一个黑圆洞就算有共鸣腔。
- **B的变化：** 空心树哨用木管形头、开阔鸣口和短根脚；若选此案，木管应有明显切面、厚度与腔深，整体仍圆墩简洁。

### E07 圆盾木卫 · 正面格挡

- **A的形象：** 约0.95—1.05H，木偶身子矮宽，宽圆树皮盾遮住前身大半；盾后能露出头顶、侧肩和两只厚脚，另一侧是简洁短拳臂。烟灰木、褐盾、浅米边缘，不增加背负武器。
- **动作与细节：** 举盾稳、受力后身体有短反应，近战时盾与拳臂不互穿。拆盾弧度、边厚、握持点、盾身距离、盾背结构和从侧面露出的躯干；盾不是贴在胸口的平圆片。
- **B的变化：** 石壳盾卫以一整片弧石盾替代树皮，盾仍有内外面与必要厚度。普通格挡和护甲特效需能分开读取，盾不能被误当成永不破的护甲壳。

### E08 胀果爆豆 · 自爆

- **A的形象：** 约0.75—0.9H，大圆果腹占主要体积，极短脚与贴身小臂，脸在上半部；果壳只有两三道粗分缝。土橙壳、深褐缝、浅奶色面区，常态无持续大面积发光。
- **动作与细节：** 接近后缩身蓄势，再用已有自爆预警和爆炸表达危险；主体失去后是死亡，不当作可投出的炸弹。拆果腹与脚的连接、壳缝深浅、收缩姿态与眼睛位置，不靠密集颗粒或写实火焰。
- **B的变化：** 空壳火种灵让一枚核心位于胸腹壳内，亮处集中；必须与E18、E19手中独立弹体区别明显。

### E09 灰面侍卫 · 首领专用护卫

- **A的形象：** 约1.15—1.3H，宽而略长的雕刻木面、稳固短腿、厚拳臂，肩部一圈短重披布；披布不过膝，头部不复制主角猫头鹰尖耳与三叶草。灰褐木、暗蓝紫布、象牙边缘，庄重但没有复杂铠甲。
- **动作与细节：** 近战重心稳，技能姿态能短暂拉开身体与手臂，让施法来源清楚。拆面具侧弧、肩布受力点、臂身间隙、披布与腰臀体积；不能把整个身子做成细柱。
- **B的变化：** 石纹仪卫保留木脸，改为岩块胸肩与少量布；技能附件按真正候选技能需要另定，不预挂一身符文或球体。

### E10 胆小菇 · 遁地追踪远程，保留

- **既有形象：** 保留已确认的大伞盖、细长菌柄、怯生眼神和孢子口；紫盖、浅绿柄、少量盖斑。原模型与概念方向见[资产交付](enemy-models-first-pass.md)。
- **后续只检查细节：** 菌盖上拱和下沿厚度、盖内侧与柄的连接、口筒内壁、眼睛贴合、菌柄压缩分区。缩地时先收柄、盖贴地，再进入地下；出土反向展开，不能只把整只模型直直下移就算完整设计。
- **与主角统一的方式：** 保持大色区、清楚明暗和简洁面片；不增加拟人手腿、护目镜、装备或另一种物种。是否降面、重做局部拓扑应等实际对照后决定，本轮不动确认模型。

### E11 盾槊木偶 · 举盾／近战／冲锋

- **A的形象：** 约1.05—1.2H，木头短躯干和厚腿，头戴小壳帽；竖向木盾略窄于E07圆盾，另一侧是一根前伸长矛。浅褐木、灰蓝盾、米白矛尖；矛杆和盾缘组成明确的竖长轮廓。
- **动作与细节：** 盾举起时真正遮住前方，近处放盾近战，远处持盾冲锋；动作要让三阶段看得出差别。拆矛杆长度与握点、盾的侧弧、肩腕角度、盾和矛的左右空间以及冲刺姿态的脚掌发力。
- **B的变化：** 橡壳枪卫换成果壳头与软布胸腹，保留盾矛关系。不能只给E07换个颜色就算完成E11。

### E12 橡果投手 · 轻载荷抛射

- **A的形象：** 约0.9—1H，宽橡果帽、小圆脸、饱满短身，投掷臂比普通兵稍长，末端用简易拳掌；手里只有一颗浅灰圆钝投石。栗棕帽、灰米衣身、淡色投石，减少额外装备。
- **动作与细节：** 扭身高举、抛物线送出，近身能做简短挥击与后跳；裙布或壳边不能妨碍腿。拆肩臂转轴、投石握持与释放点、帽沿遮脸量、后跳重心和足底回收；不做现实成人投手比例。
- **B的变化：** 苞衣投手用少量卷叶肩片替代果帽，叶片也要有折叠、压叠和自由边，不能是一圈硬尖刺。

### E13 黑圆头幽灵法师 · 上方落弹，保留

- **既有形象：** 黑圆头与两个小亮眼睛、紫色巫师帽、圆润上身向下收成幽灵尾，小法杖悬在身旁。无手掌、无短臂、无腿脚、不加南瓜；不回到旧蘑菇法师方案。
- **后续重点拆解：** 帽檐厚薄与前后起伏、帽锥的渐缩和末端弯折、头身连接的饱满程度、尾部截面渐收与转弯、杖头体积和悬浮距离。可以少褶皱，但帽子不能成为硬圆锥，幽灵尾也不能成为一片平三角。
- **动作边界：** 漂浮是外观，仍遵循地面导航；蓄力、杖的预备和释放要读得清。落弹释放遵守真实事件与落点规则，不因本计划增加飞行或改变法师采样目标的时机。

### E14 根须追猎兽 · 转向追踪冲锋

- **A的形象：** 约0.65—0.8H高，身长明显大于E04，低伏四足、紧凑木面、大前爪；背部几片贴合的根皮作厚块，后身逐渐收窄，无密集枝叉。暗褐、灰紫、少量淡琥珀眼色。
- **动作与细节：** 准备时持续看向目标，冲锋能有限转向，贴近衔接爪击。拆胸腹截面、前后腿长短、爪与腕的重量关系、转向时肩胯扭转和四足稳定；它不是E04的换色直线撞击体。
- **B的变化：** 裂壳猎偶用前倾双足与大拳臂实现相同定位，窄腰仍有真实躯干体积。若选双足可减少新四足动作成本，但必须保留追猎与追击后近战的姿态特征。

### E15 折披俯冲偶 · 起跳、滞空、下扎

- **A的形象：** 约0.95—1.1H，头罩前窄后厚，短肩披两角形成向后收的三角形；躯干紧凑，粗短落地腿比肩披更实在。灰蓝布、浅木脸、暗紫腿脚；披边不挂羽毛或碎布串。
- **动作与细节：** 起跳先收腿与披角，短暂滞空团身，再沿目标方向下扎并落地展开。拆头罩与胸腹轴线、披角自然下垂／受风关系、团身的负空间、落地脚掌和恢复重心；不把动作做成一直在天上飞。
- **B的变化：** 钝喙跃猎者使用短钝喙面和短翼形肩片；喙只是一块简洁前突，不做写实鸟脸或大翅膀，不新增飞行敌种。

### E16 石头人Plus · 保留的重击方向

- **普通持锤版退出：** 用户于2026-10-26明确可以去除持锤石头人；后续设计、概念图与制作清单均不再保留该方向。历史源文件的存在不表示仍是当前选择。
- **Plus版：** 保留黑灰不规则岩块、深眼窝和小块暖黄眼睛；无武器与多余装饰。岩块像从地形取出后组装，轮廓基本稳定，不改成规整立方体，也不做满身碎石噪声。
- **逐项复核：** 肩胸大块与前臂块的尺寸差、胸腹拼接、肘膝关节空隙、拳掌受力面、脚掌支撑与抬臂净空。检查双拳砸地接地点，不能用相同外形的小动作替代重量。
- **关系边界：** E16外观继续采用纯岩块Plus方向，生产接入仍按当前档案与验收状态维护；不能擅自把Plus等同于所有精英单位。

### E17 叶刃回旋客 · 单段突进大回旋

- **A的形象：** 约0.95—1.05H，方圆小头、厚实短腿、贴身短围布；一把宽而弯的叶形木刃横向展开，刃的宽面比装饰更醒目。灰米身体、暗棕柄、低饱和莓紫或灰青刃面。
- **动作与细节：** 起手收刀、突进转体、大幅水平回旋，再收势站稳。拆刀刃厚度、弯度和宽窄、握点、刀与躯干间隙、肩胯跟转、扫击时脚下重心；不通过多加几把刀表现危险。
- **B的变化：** 镰叶木偶将刃改为单片镰形，头换圆木；仍是一次清楚的大回旋，不能和E20的逐段连击混成同一节奏。

### E18 葫芦掷弹精 · 向前投出炸弹

- **A的形象：** 约0.85—1H，葫芦般上小下大的圆墩身，头部短壳帽，两条短臂在前方托一颗独立圆壳弹；侧面能看到弹与身体分开。土黄、暗灰布、暗橙弹体，不背大型炸弹筐。
- **动作与细节：** 身体后仰蓄势、向前送弹、空手回位；主要读向前的弹道，不使用高举过头的主要轮廓。拆圆弹壳厚、握持接触、释放距离、手臂前送和身体后仰平衡；独立弹体要离手，不让自爆核心“飞出去”。
- **B的变化：** 罐帽炸果灵把头改成低圆罐帽，保留一个显眼弹体。不要加写实引信、电线和金属零件堆叠。

### E19 厚壳抛弹手 · 高抛炸弹、近战与后跳

- **A的形象：** 约0.95—1.05H，与E12同一类投手身体，帽壳更厚更宽，手中载荷换成更醒目的深色大壳弹。偏暗栗棕、奶灰身、土橙弹体；与E12浅灰投石形成形体和明度的双重区别。
- **动作与细节：** 保留E12高举抛射、近战与后跳的姿态语言，但大弹带来更明显的肩身蓄力。拆帽壳厚边、手臂容纳大弹的间隙、仰身幅度和弹体离手轮廓；不能仅换材质、不看大载荷是否穿头。
- **B的变化：** 瓢壳投弹偶采用宽壳头与短布身，仍是一枚独立大弹，不做成E18的向前小幅送弹姿势。

### E20 双枝拳斗偶 · 分段突进连击

- **A的形象：** 约1—1.15H，短宽木脸、厚前臂、大木拳、稳固短腿，胸腹是少褶皱的紧凑短衣。暖灰木、暗红褐衣、浅米拳面；左右基本对称，不挂多余兵器。
- **动作与细节：** 每段都有短促收拳、向前送身、命中与重新找重心，整套结束后明确恢复。拆拳面体积、前臂与肩的粗细梯度、拳身间隙、胸胯反向转动与步幅；不得用一段挥击加匀速滑行充当完整连招。
- **B的变化：** 短棍连击客把木拳改成短双棍，维持紧凑范围。连击段数、转向与突进距离依当前行为配置，不在美术提案中另造固定三连或新机制。

### B01 空心树王 · 独立首领候选

- **A的形象：** 外观约1.7—2H的比较提案，宽树干胸腹、厚根足、两条巨大短臂，头部嵌一块有浅曲面的雕刻木脸；顶部几根低矮厚枝形成冠形，数量少、轮廓清楚。深木、灰褐与奶白切面，少量琥珀眼色；可有短肩布，但不堆盔甲与饰品。
- **现有能力的表现：** 挥击依靠大臂，尖啸由胸腔／脸部姿态展开，冲锋用整体压低重心，召唤用双臂张开与集中光效承载。65%与33%阶段解锁按现有机制表现，不擅自新增长枝、换体型或额外头脸。
- **重点拆解：** 树干的前后厚度与内腔、木脸和胸身的嵌套、冠枝根部与头顶连接、肩臂可动空间、根足支撑、正常镜头下的头顶遮挡。大体型仍要检查场景净空，不能仅放大一只E01。
- **B的变化：** 岩木古守用岩块构成厚身体、木脸与少量根足连接，保留宽厚巨臂。不直接复用石头人Plus再放大；首领需要能容纳现有全部能力的独立轮廓。

## 每只模型开始前要交代清楚的拆解表

此处为后续制作模板，本轮没有声称已为21个对象完成参考搜集与细节定稿。执行要求来自用户本轮补充，完整记录见[建模经验](../ArtSource/modeling-notes.md)。

| 层级 | 必须写出的观察 | 对照证据 |
|---|---|---|
| 整体 | 身高宽厚、头身比、重心、轮廓、负空间 | 主参考正／侧／背／三分之四视角；与主角同尺度比较 |
| 头脸 | 外轮廓、正面曲率、侧面截面、厚度、眼孔深度与眼睛位置 | 头部近景与侧面；必要时画截面 |
| 躯干 | 胸腹腰臀、四肢支撑、头身连接、衣物内部的体积 | 临时隐藏外衣的真实模型截图 |
| 衣布 | 悬挂点、包肩量、领口叠压、牵拉褶、松垂、自由边与下摆 | 材料实物或相近模型参考；灰模多视图 |
| 硬质件 | 石块拼接、木头切面、盾／刀／帽的厚薄、握持与关节间隙 | 局部拆件、线框或截面与同角度对比 |
| 色彩 | 大色区面积、明暗层次、识别色占比、木布石的区分 | 无复杂灯光的纯色预览及实际场景截图 |
| 动作 | 起手／执行／恢复、关键受力点、足底、穿插、图案贴合 | 真实模型关键姿态，不能只用参考动画视频 |
| 结果 | 哪些已对齐、哪里仍不同、哪些是缺图后的暂定补全 | 差异清单与修改后的并排截图 |

优先修大形，再解决结构关系，最后补局部细节；每层都要回看参考。用户没逐字描述到的厚度、曲率和叠压不能省略，也不能凭空添加装饰填满空白。候选设计的明显偏差应先主动修正，再交用户挑改。

## 制作与性能边界

这是后续落地约定，本轮不运行生成、不消耗混元额度，也不新增引擎功能。

- 先在已选图稿上决定Blender直接建模还是沿用图生3D产线。几何与厚度需要精确控制的造型优先在Blender逐项构建；生成模型也必须经过同样的形体对照与整理，不能跳过。
- 简化从看不见或不起识别作用的细节开始。面数、材质与骨数按实际造型和同屏测试定，不能给所有敌人硬套当前角色的15骨或同一三角面预算。投手等相近结构可共用基础骨架，四足、蘑菇、幽灵按自己的身体设计。
- 材质尽量复用少量实色或小调色板；少建透明层、少做独立发光碎片，布料先采用少量辅助骨，不默认实时布料模拟。实际成本包含绘制调用、材质、阴影、蒙皮和特效，不能仅凭低面数承诺性能。
- 持续遵守[美术接入流程](art-onboarding.md)：保留概念图、参考拆解、`.blend`、可编辑脚本、导出候选和版本备份；运行模型经视觉档案接入。快速动作保持已验证的60fps导出／导入，伤害与格挡对齐真实事件。
- 灰模／模型都应在正常玩家镜头看一次；绑定后再检查真实移动、攻击、受击与死亡，最后测同屏战斗。技术通过与外观认可分开记录，不把演示场景当生产验收。
