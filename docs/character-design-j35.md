# J35 · 地图导航与行为压力基础

2026-10-20按用户要求先做地图／导航／有效点与生成资源基础，再实现敌人清单。精英附加特性尚未设计，额外压力仅预留参数、生产值为0。

MapManager增加严格TryPath／TryValidPoint／TryRingPoint，验证导航同步、投影容差、完整可达路径、投影后距离、身体净空及单位占用。失败返回false，不把玩家脚下当作成功。普通／较大身体按净空尺寸分配导航地图；Rebuild清理自有档案、失效路径版本，等待同步后才恢复可用。场景退出自有区域延迟释放，避免父节点退树时立即Free导致引擎错误。

UnitNavigation通过真实导航网格路径给CharacterMovement发送移动意图；追击、保持距离、撤退、换位接入路径跟随，停止使用射线侧移作为行走路径。射击视线／身体碰撞保留各自职责。新刷怪入口改用严格选点，只有点位成功后才入树和扣预算；失败保留资源并重试。修正未成功生成任何敌人时被误判为Encounter完成的分支。旧Vector3返回值接口仍用于历史调用，严格生产刷怪和新敌人行为使用Try接口。

EnemyBehaviorPressure共享表给行为定义成本，EnemyConfig.PressureBehaviors引用条目，最终SpawnResourceCost＝各不同条目压力之和向上取整、最少1。随机抽取Weight独立。未知条目不能按便宜回退价生成；旧未配资源仍可用Cost回退。现有8种普通敌人初始压力保持原成本；新敌人组合对应压力在共享表中预设。普通精英的既有属性增强保持，未来附加词条压力接口默认0。

验证：双构建0警告0错误；真实导航专项28通过／0失败，包括绕长墙实走、断开岛拒绝、占用检查、投影后范围、大身体档案、重烘桥梁连通，以及实际刷怪成功／失败时的资源计数。D批91、身体31、飞行42、弓39、蓄力80、角色115、龙箭42、符文83全部0失败；Main68.38秒，八指标与J11逐字一致。四份真实存档不变、rune.cfg不存在、selftest.flag清理。见[完整证据](character-design-j35-evidence.log)。失败现场保留，首次修正导航同步时机及生成失败误结算，后续修正退出阶段的立即Free。

本批为基础检查点；后续敌人攻击预警、护甲／格挡反应和11种组合仍在同一任务继续，不把这些功能提前标完成。不包含新模型美术与精英词条设计。
