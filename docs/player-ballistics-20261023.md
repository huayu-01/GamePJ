# 玩家投射物修正（2026-10-23）

本次对应玩家反馈第9、10项及角色A投射物速度：保留真实技能槽输入、松手冻结、动画ATK发射与飞刀右键固定60°，修改后续飞行与外观。整批构建和游戏验收由主代理统一持锁执行；本文的测试段先记录入口和断言范围，不冒充已经通过。

## 当前规则

- 弓箭从离弦起连续受重力。没有有效标记目标时保持普通抛物线，不自动锁定普通敌人。
- 前2.5米保留出手方向；达到距离后才允许追踪带`Mark`的敌对目标。此处“一开始不能追踪”结合后续要求解释为先飞行再制导；追踪权限仍来自弓右键“刹那之眼”产生的标记。
- 追踪采用三次贝塞尔曲线，起点切线延续当前速度，终点取目标真实身体碰撞形状中心。移动目标更新终点，飞行仍逐物理帧经过原射线／形状扫掠，地形可拦截。
- 曲线制导时不额外叠重力。目标失效时保留当前速度恢复重力；重新找到合法标记后可再次接入曲线。已经穿透命中的目标从追踪候选排除，避免掉头追打同一身体。
- 飞刀默认同样连续受重力。仅“花心”等明确授权无标记追踪的构筑允许索敌，并同样保留2.5米出手距离。右键初速始终在准星两侧各30°范围内，更多飞刀只缩小间隔。
- 能量波保持既有直线、无下坠和穿透格挡特性，只调整速度。

抛物线用匀加速度的步前后速度平均值积分，30与120物理步长应得到一致轨迹。平射的落点由初速及发射高度决定；接近竖直上射时水平距离短、滞空长。中等仰角可能比平射更远，这是重力下正常的抛射规律，没有按镜头角度人为缩短射程。
