# 更新与修复验收表

本轮按用户的 `F:\Godot项目\3d肉鸽雨中哈迪斯\更新&修复.txt` 逐项执行，不派子代理。可编辑的主清单是[验收工作簿](../outputs/acceptance-20261026/更新与修复验收.xlsx)，状态以工作簿为准。

## 如何编辑

- “验收清单”页可筛选、排序，并直接改验收标准、玩家验收及用户补充。
- 在表格末尾按Tab或插入表格行可新增项目，编号使用未占用的正整数；选择处理状态及玩家验收状态，汇总和下拉预留到1000行。
- “已修复”表示已实施并完成记录中的开发验证；“玩家验收通过”由用户填写，开发验证不会自动代填。
- “修复记录”页每次追加记录，按编号对应清单，不覆盖过去的失败与复验说明。
- 4K／100敌人／60帧必须记录实际硬件、输出与渲染分辨率、画质和有效战斗帧耗时；代码优化完成不能代替该项实测通过。
- 性能项已按玩家授权实施分配、空闲表现更新与地面避让，见[实施和实测记录](performance-results-20261027.md)。100敌人1%低帧仍未达60，不能标为已通过。
