# 地表方块色差修复（2026-10-30）

用户指出地形颜色有方块，并要求树叶暂时放下。本轮只修地表与草根共用的颜色生成；树叶的片状感和团簇不足仍是待解决问题，不视作已验收。

## 原因与修改

关闭全部草地后，地面依然存在矩形硬色差。Ground本身是一整块网格；道路已隐藏，没有额外矩形苔藓贴片。这排除了新加4×4米草地分块作为这些色差的来源。

`Assets/Effects/meadow_palette.gdshaderinc`原先用`fract(sin(dot(...))*43758.5453)`生成噪声格点值。在当前4070 Ti／D3D12 Forward+路径上，相邻格子公共边界出现明显不连续。仅将该函数换成整数格点哈希，保留原平滑插值、两层频率、调色范围与土色混合，即消除方块。

地面片元与草根顶点继续调用同一份共享函数。整数运算后取24位转浮点，避免正弦近似以及浮点表达式优化造成不稳定格点值。新哈希会重新分布自然色斑位置；草簇生成位置、密度、风动、占地排除均不变。

[Godot官方仓库中的历史报告](https://github.com/godotengine/godot/issues/84871)记录了类似的正弦哈希噪声不连续，[关联讨论](https://github.com/godotengine/godot/issues/67150)讨论了浮点计算和渲染路径差异。历史报告主要是Vulkan；本轮结论依据本机D3D12的前后对照，不将具体驱动内部原因当作已经证明。

## 实际验证

新增`--ground-color`验证分支：在真实GPU上输出1024×1024噪声图，覆盖坐标[-8,8]及正负格点边界；除哈希函数外，新旧代码相同。检测每条网格边界两侧的相邻像素差，阈值0.04。

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 检查的边界像素对 | 30720 | 30720 |
| 明显跳变数 | 7497 | 0 |
| 最大灰度差（0～1） | 0.956863 | 0.003922（8位图的1级） |

随后在同一场景、同一机位、同一光照下，分别拍旧地表、新地表和恢复铺草的画面。近景与全景均已人工查看；硬矩形色块消失，连续色斑保留，草根与地表共色。

入口`_tools/verify_ground_color.ps1 -Round round-2`：Debug／ExportRelease均0警告0错误；无头18、实渲染27、试玩22项全部通过，stderr为空，五份真实存档逐字节不变。自动窗口保持不获取键盘焦点。本轮没有重新做帧时间基准，不推断性能增益。
