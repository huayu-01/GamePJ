# 树叶柔和材质与建筑禁草区（2026-10-30）

已接入独立丛林草地样板 `Scenes/Debug/GrassShaderLab.tscn`。当前树仍是可替换的示例模型；正式关卡没有整体替换成样板。保留草地每面积密度6、慢风0.45、无角色压弯，以及原关卡碰撞和导航。

## 草地分区

4×4米的 MultiMesh 分块继续负责绘制裁剪。建筑占地在生成前排除：先按世界包围盒筛选相关禁草体积，再在体积局部坐标精确判断旋转／缩放盒。某个体积包含整块地面高度范围的八角时，直接跳过该块，不创建实例、不采样地面；边缘块只排除被覆盖的候选草根。

各块有独立随机种子，每个候选固定消耗相同随机数。新增占地不会改变未受影响块；边缘块保留下来的全量实例也保留原位置、朝向和尺寸。普通档仍显示每块65%的实例。此前全场共用随机序列已改为分块序列，因此不要将旧19289簇与当前19020簇的差值全部当作禁草收益。

两种配置方式：

- `ShaderGrassPatch.RegisterSceneExclusions(arena, ground)`：忽略指定地面，自动收集贴地、启用的静态盒形碰撞；架空盒不会自动登记。其他形状仍沿用原地面采样判断。
- 建筑根节点直接挂一个或多个 `GrassExclusionZone`，设置局部 `Size`、位置和旋转。它只提供体积，没有碰撞和逐帧更新；只要有显式节点，该建筑子树便使用作者配置，`Enabled=false` 可关闭占地排除。复杂占地可用多个盒子拼接。该体积需要覆盖草根所在高度。

也可在 `Build()` 前调用 `RegisterExclusionBox(worldTransform, size)`。本轮是场景生成时读取占地，没有实现动态建造／拆除后的自动局部重建。禁草开关不替代地面射线采样规则：射线仍会拒绝高台顶面和陡面，架空区域是否长草也取决于能否采到地面。

同种子、同地面、同密度的运行结果：

| 检查 | 无禁草 | 有禁草 |
| --- | ---: | ---: |
| 100×100米全场生成射线 | 31543 | 29712（减少5.8%） |
| 全场普通档草簇 | 19124 | 19020 |
| 全场非空绘制块 | 623 | 623 |
| 12×12米试验区，旋转45度占地，全部草实例 | 334 | 185 |
| 同上，地面射线 | 335 | 186 |
| 12×12米完全覆盖 | — | 跳过9块，0实例、0射线、无逐帧更新 |

当前场景建筑占地较小，许多建筑下原本也会被地面射线拒绝，所以主要节省生成工作，非空绘制块数没有降低。更大的整块占地才能进一步省掉对应 MultiMesh 的绘制和实例内存。本轮未采集帧时间或GPU耗时，不宣称帧率提升。

## 树叶材质

新增 `SoftFoliageStyle` Resource 和 `Assets/Effects/foliage_soft.gdshader`。`JungleGrassScenery.TreePrototype` 支持更换 PackedScene，`FoliageStyle` 控制风格；默认识别材质名以 `Leaves` 开头的表面，其他命名可修改 `MaterialPrefix`。

叶面的原始法线控制温和的侧向减弱，受光法线单独朝树冠外侧与上方混合；保留原叶纹理、顶点色、材质色及UV变换，保留树干与网格。裁切和MSAA覆盖抗锯齿配合柔和漫反射。树冠范围从当前叶 surface 自动计算，不写死模型尺寸。投影阶段保持原叶覆盖，避免镜头角度改变树影。

`NormalRoundness=0.78`、`SideFade=0.24`、`WrapLight=0.35`；侧向减弱刻意小于草地，保住树冠整体覆盖。这不是将树叶强制改成十字片：未来采用叶片卡的树可复用材质；当前模型保留自己的叶面结构。运行中同类表面共享缓存材质，不为每片叶挂脚本。参数按构建时读取，调整后重新构建样板。当前74个叶表面共用至多2份材质，松树和扭曲树原型也通过叶面识别／自动范围验证。

实现参考 [Godot 4.7 Spatial Shader 官方文档](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html)，包括视图空间法线、覆盖抗锯齿及独立投影阶段。此前两个B站视频未能实际播放，本轮没有声称观看到额外视频内容。
