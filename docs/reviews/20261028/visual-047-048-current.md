# 047／048 实施：C指示器与简化毛玻璃UI

2026-10-28。用户确认新版卡牌并授权落地。本页替代此前仅做概念稿的边界；[概念阶段原文](visual-047-048-concept.md)和[初次评估](visual-047-048-initial.md)保留设计过程。

## 已实现的页面规则

- 奖励卡中央为灰色透明底，边缘逐渐磨砂，使用项目原生文字和SVG。卡名区分类别色：异化紫、进化青、强化绿、特化蓝紫；右上角只放类别小图标，不再重复“异化／强化／进化”等类别文字。描述统一近白正文色，不随卡名变色。
- 前置、互斥及适用限制集中在图鉴，奖励卡和本局构筑只保留效果。图鉴前置标题为赭色、互斥标题为紫色，保留文字标题和完整资料，不依赖颜色独自表达含义。
- 构筑与图鉴使用较均匀的乳白磨砂底和深色正文。构筑保留左半库存、右半详情、悬停与键盘焦点；既有特定等级名称继续读取 `RunBuild.DisplayName`，不新增堆叠角标。首批简化图标覆盖火、生命、力量、护甲、速度、贯穿、弹射、流血等，未有专属图形的项目沿用已有专属图或类别回退，未声称全目录图标均已重绘。
- 玩家页面不展示控件状态示例。底部为当前页面的按键提示；搜索聚焦时隐藏J关闭和条目方向键提示。按键栏更新保留磨砂阅读底，避免浅色文字和背景相互干扰。
- 打开上述三页时隐藏战斗HUD，关闭后恢复其先前可见性和处理状态；在奖励页上覆盖设置时仍保持隐藏，避免HUD透过卡面与文字重叠。游戏暂停、输入保护、设置返回链继续由原路由管理。

奖励页支持数字直接选择、鼠标选择、方向键浏览与Enter／Space确认当前焦点。增加单次提交保护，解决按钮与键盘回退可能在同帧重复通知的问题。候选对象、奖励资格、唯一性、授予参数及局内效果未因换肤改变。

## C指示器接入

正式 `SkillIndicator` 预制体已增加稀疏笔触和固定细边，压低填充与发光；玩家青蓝、敌人红，深色底边辅助地表对比。圆形范围和直线方向仍由原调用参数提供，前摇进度由攻击生命周期只读传入。曲线预览继续使用已有弹道采样。

使用正常3D深度测试，人物和不透明场景可以遮挡局部提示。没有全屏置顶合成、穿墙材质或新增碰撞。圆形使用缓存的九点地表采样改善缓坡贴合，原半径、长度、宽度、锁点和伤害时机保持。隐藏、中断、死亡与退树沿原生命周期清理，各实例笔触材质和动态网格独立。

本批实拍与自动化覆盖正式场景及已有敌人动作；没有把复杂桥梁、跨楼层和所有陡坡宣称为已逐一视觉验收，也未测最低设备性能。概念图中的触发短白锋、退出残片属于后续可选美术细化，本版优先清楚轮廓和可靠清理。

## 材质与内容边界

`GlassUi` 提供局部主题，沿用项目Noto Sans SC。每页使用一次屏幕拷贝与共享mipmap采样，文字和图标在玻璃之上绘制；没有每卡单独全屏高斯。浅色资料面与深色奖励卡共享圆角、细边和焦点强调。

危险契约及旧四路线当前在主工程已停用，本次没有恢复权重或投放。实拍使用当前有效的灼烧弹、力量与发散；用户提到的危险契约紫色规则同样适用于异化类别。既有GLB、骨架、技能机制和真实存档均未作为换肤对象。
