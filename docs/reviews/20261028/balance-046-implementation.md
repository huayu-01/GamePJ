## 护甲的统一口径

单次命中先按命中前护甲状态计算整击减伤，再依次扣**护甲→临时护盾→普通护盾→生命**。同一击破甲后的余伤不重新放大，只有生命余伤再乘`IncomingHealthDamageMultiplier`。这次只是纠正文档和注释。

常规精英额外护甲仍为`max(120,最终最大生命×30%)`，再加原型基础护甲；出生/显式回满初始化，不由普通`RefreshStats`补回损甲。玩家、普通护甲增幅、死铠、重铸与基础护甲没有一起变比例。有甲免普通受击打断，首领常驻霸体免控。
