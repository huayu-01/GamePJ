# 047／048 当前方向：C指示器与简化毛玻璃UI

2026-10-28，按用户最新反馈修订。本文优先于[初次评估](visual-047-048-initial.md)中的旧建议；实拍、参考游戏研究和问题证据继续保留，旧顶层方案、纸木主题与页面状态示例不再执行。

## 已确认的推进边界

1. 指示器以 **C「涂抹刀锋」** 为推进方向。用户倾向已记录，不再反复要求重选A／B／D，也不自动混入A的叶脉。
2. 用户已撤销“场景顶层、仅次UI/HUD”的要求。采用**场景内正常深度关系**，贴地并受遮挡，不默认穿墙，不把整片预警提升成屏幕覆盖层。
3. UI和图标均简化：移除纸张、木框、叶饰、卷轴及复杂插画，采用轻薄毛玻璃、统一线性／少色图标。
4. **玩家页面不显示状态示例**。默认／悬停／选中／禁用仍是内部控件规范，底部空间用于当前有效的按键／鼠标提示。
5. 当前展示的三选一卡牌页采用**中央偏透明和灰、边缘再毛玻璃**。构筑与图鉴的长文区域暂保留较均匀的磨砂底，保证阅读，不机械复制卡牌透明度。

本轮继续做设计稿与方案记录，没有替换生产源码、材质、UI或GLB，没有改真实存档、验收表或向其它会话发消息。

## C版：美术收敛与常规遮挡

保持一条清楚的固定范围边界，内部2—3条淡宽笔触；敌方珊瑚红配极薄深莓底边，玩家碧青配深靛底边。短白锋仅在触发瞬间出现，不让整个危险区泛白。压低现稿中偏高的爆发笔触，玩家瞄准弧线保持细稳；结束立即撤掉闭合危险线，只留少量断片。

真实圆／盒／球形命中体、精英缩放、落点、锁点、取消及伤害帧沿用当前数据。笔触不能定义碰撞范围，不能为播完动画延长前摇。时间进度由攻击生命周期只读提供，暂停／打断／死亡／退树沿原流程清理。

- 提示属于3D场景，使用正常深度测试；只用很小的地表偏移避免闪面，不把大盘抬成悬浮层。
- 实心墙、桥和不同楼层按空间关系遮挡；不在错误楼层画危险。坡面要贴合实际地表，不能只压中心后整张盘悬空。
- 人物可以挡住其后的局部提示。先以低填充、清楚细边、地表对比和适当植被处理保障阅读；只有真实画面证明确实长期完全遮没关键边缘时，才单独评估局部补线，不能恢复全场景置顶。
- 检查透明排序，不能把提高RenderPriority当深度替代；隐藏／取消不留透明盘。UI/HUD自然在世界画面上方，**不再为预警预留CanvasLayer=2**。
- 删除旧专用全屏合成、遮挡类别缓冲和跨Viewport深度共享的必选依赖；复杂路径只由实际问题与性能证据决定。

验收必须覆盖自由镜头高低俯角、墙边、桥上下、坡地、人物群聚和明暗地表；逐项核对范围／触发时刻未变、轮廓能辨、不投到错误地面。静态概念板不等于这些场景已通过。

## UI材质与图标

### 卡牌：中央透、边缘雾

中心用中性烟灰与较低遮盖稳定色调，仍看得出场景形体与色彩；中部清楚或仅轻模糊。接近外边约12—20个1080p逻辑像素时，逐渐提高模糊与少量雾白，圆角连续过渡，最外侧仅一条柔和细边。不能整卡乳白，也不能做成厚玻璃相框。

原型可从中心约25%—35%遮盖开始调，这只是起始值。**文字对比优先于统一透明度**：正文所在区域可增加柔和灰色背衬，主字近白配极薄暗衬，不能为“更透”牺牲浅地面上的阅读。目标正文≥4.5:1、必要图标≥3:1，按最终背景混合像素测，不由概念图直接宣布通过。深色键帽配浅字，或浅色键帽配深字。

选中／悬停保留克制的青色轮廓和既有光圈约定，不改变尺寸。当前生成稿中卡边缘仍略亮、角部雾化稍厚，正式材质需压低亮度并按UI缩放调边宽；生图只是材质方向，不能冒充真实shader效果。

构筑、图鉴为长文阅读面，使用较均匀且稳定的乳白磨砂底与深松灰文字。与卡牌共享薄边、圆角、字级和图标语法，按信息密度调整透明度。

### 图标与信息层级

专属图标回答“是哪项”，类别小标回答“哪类”。契约＋裂心、罗盘、双灵偶保留简洁识别轮廓；统一圆头线条、相近视觉重量、最多一小块平色。复用并整理现有SVG系统，不用大星爆替代全部同类能力，不把图标做成新的物品插画。

生命、护甲、护盾保持不同形状；类别、条件与代价仍有标题／分组，颜色只辅助。构筑继续左半库存、右半详情，不显示全项层数／上限；只有既有特定等级增幅可显示等级，不改资格、唯一性或候选过滤。

机制描述保留必要文字，从配置／本地化读取，插画不能新增投弹动作、金币收益或攻击机制。新稿已删除原纸面稿的这些扩写。沿用项目Noto Sans SC，1080p正文建议20—22px、标题28—32px、辅助最小16px；长标题2行，长详情独立滚动，不无限缩字。

默认／悬停／选中／禁用仍需在控件上正确表现，但不展示四张教学小样。完整键栏须分别验收列表焦点、搜索焦点、设置叠层、输入保护期和滚动区域，不能靠一张静帧宣称完整支持。

## 工程原型与验收

毛玻璃建议采用**一份锐场景图＋共享模糊图＋边缘遮罩**：中央主要采样锐图并加灰，边缘逐渐转向模糊图与轻雾白。文字／图标／键帽后绘制，不参与背景模糊。所有同屏面板共享场景采样和模糊结果，不能每张卡各做全屏高斯。

暂停界面可在打开或场景内容变化时更新背景，只动画材质和控件；独立模型展台不应被背景模糊或反复重绘。低画质可降低模糊分辨率／半径并提高稳定灰底，保持相同文字和按键可读性。还未测过最低设备，不承诺毫秒数，也不声称已有真实玻璃shader实测。

下一步先核对卡牌v3的透明度／灰度／边缘雾化，再以独立控件原型落实材质。C方向已记录，不再重复选指示器。保持“只做方案和稿、不全量替换生产”的本轮边界；获得后续落地指令再改生产资源。

原型验收先处理奖励不遮候选、数字／焦点确认语义与Esc返回链，再推广构筑／图鉴。覆盖720p／1080p／4K、长文、明暗底图、搜索输入、滚动和暂停叠层；范围／伤害时序、奖励一次生效、唯一性、等级显示与存档只读规则保持。

工作量粗估：C美术收敛3—5人日、常规深度／时序接入与场景验收2—3人日；共用玻璃材质与组件1—2人日、奖励布局／按键1—2人日、构筑／图鉴推广2—3人日；首批12—16个图标约2—4人日。不含全量图标与模型制作，不是排期或性能承诺；旧顶层合成不再计入必选依赖。
