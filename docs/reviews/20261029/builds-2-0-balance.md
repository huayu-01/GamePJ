## +30攻击：分配给一次出手，不给每个伤害实体各发30

建议独立参数`AttackPowerAdd=30`，**不要**直接改所有Projectile/AttackHitbox.Damage += 30。以同一目标的一次直接出手为单位，给本次所有组成段权重`w_i`（合计1），在出手时冻结：

`B_i = (原始本段伤害 + 30×w_i) × 本段合法蓄力/连招系数 × 出手伤害倍率`。

暴击、目标增伤按当前攻击链只算一次。这里的权重用于药剂加项，**不重分配原武器伤害，也不改变巨人已裁定的每次命中附伤**。一枚穿透弹对多个不同敌人仍能各兑现自己的那份加项，不按敌人数稀释；同一目标的多弹/重复跳伤共享总预算，未命中份额不返还。

| 场景 | 错误实现 | 建议实现（不含暴击/成长） |
|---|---|---|
| 原飞刀3把、每把12 | 每把+30，合计**126** | 各分10，合计**66**，原36＋药剂30 |
| 刀舞首刀＋3追击刀 | 4枚各+30，光药剂就+120 | 整轮同根CastId，按12:8:8:8分配30，即10/6.667/6.667/6.667；合计仍额外30 |
| 满蓄旋转8跳 | 每跳+30，额外240 | 整次持续段分配30，每跳额外3.75；晚进圈/打空不补发余份 |
| 弓满蓄×1.9 | 把30先加，再在飞行/命中又加一次 | 根攻击加项只计算一次；若加在基础攻击乘区，满蓄合法放大为额外57，应明确是蓄力收益而非多弹复制 |

含前冲伤害的死亡收割，30要在前冲与全部旋转段间重分，不能前冲领30、旋转又领30。斜阳穿隙将一次下刺/落地按18:40分配30，后续无限留场的被动驻枪接触不重复领药剂加项；换位产生新施法才有新预算。否则同一根长枪留场多久，就能平白重复产生多少份30。

近战连招当前每个真实手动段有独立CastId，可各按一次出手获得预算；持续旋转是一次持续释放，不能把每跳新CastId当成新手动出手。刀舞追击须继承根出手、暴击/攻击快照并有`不能再生刀舞`标志；不能仅凭“又创建了三个AttackInstance”重发药剂30。基础能量波单发10→40是固定+30本身的高收益，应如实保留，不冒称所有武器都只增强同一百分比。

自动电磁圈、独立持续状态和反伤不再领取固定30；有主攻击快照的衍生效果按各自倍率从已冻结的B派生，不再加第二次30。**`IsSecondary=true`本身不保证所有效果都不再乘**：现有[SpecializationServices.DirectHit](../../../Scripts/Rewards/Specializations/SpecializationServices.cs)默认仍可能调用RollHit，而[巨人](../../../Scripts/Rewards/RuneRules.cs)读取每次RollHit的最大生命附伤。新自动电圈推荐用明确冻结数值的结算入口；刀舞等手动武技组成段继续按既有真实命中口径处理巨人，不能借药剂归一化顺便削它。

## 兼容性与首版验收重点

1. **大刀阔斧范围只乘一次。** 当前三档范围×1.3/1.7/2.5是替换上档，不是三档相乘。死亡收割2.4m最高变6m，斜阳穿隙2.6m最高变6.5m；若再有巨化×1.2，分别7.2/7.8m。预览、扫掠、落地AOE与实际碰撞共读有效尺度，不把模型根缩放再重复乘一次。新电圈/能量罩不因“圆形范围”自动取得近战范围增幅。
2. **斜阳穿隙首版与气贯长虹互斥。** 当前[气贯长虹](../../../Config/Tables/Upgrades/evo_rainbow.tres)不是减半，而是`CooldownScale=0.3`并让直射长枪无限穿透。若原样迁移，新CD2→0.6s，急速期间0.3s；落地40AOE可被高频刷新，且“原来已经打范围”时无限穿透的收益不清楚。当前调参器还只消费直射分支。首版双向互斥能避免暗中失效或错误叠乘；未来若要兼容，必须另定义穿刺轨迹和AOE各获得什么，不能擅把既有0.3改成0.5。
3. **同名嗜血使用独立身份。** 现有[evo_bloodthirst](../../../Config/Tables/Upgrades/evo_bloodthirst.tres)是战神印击杀持续回血/暴击特化，不能被新通用武技1吸血覆盖。新效果应有独立数字身份和明确说明，两者合法并存时分别统计；泛用LifestealRule当前读取HealthLost且不筛武技槽，不能只把Ratio改成0.01就当完成新要求。
4. **手动与衍生必须可区分。** 秘法切刃结算时每目标一次、死亡后取消未执行部分；刀舞不能刀生刀；金蝉只在瞬移成功后清空阈值；斜阳换枪先停旧命中体，取回解锁武技1。伤害归属保留本人，真实击杀可正常触发已裁定的心之钢，未命中/取消不伪造击杀或额外奖励。
5. **冷却从真实收尾算，不只看CD数字。** 秘法切刃最多约0.9+5秒一轮；死亡收割满蓄含2秒蓄力、最多0.667秒前冲、4秒旋转再加3秒CD，不能宣称每3秒一套满蓄。能量罩/灵魂眼为独立留场效果，短启动后允许继续手动战斗；基础罩覆盖约2/3.15=63.5%，眼约10/15.2=65.8%。急速下可出现同来源持续刷新，必须“只保留一份”而非叠实例；这属于临时防御/标记成型收益，不自动削弱已给出的3/15秒CD。
