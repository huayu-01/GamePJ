### 078 风剑效果没正确触发 —— ⚠️ 代码已具备，缺证据

旧 bug：拿到后只发射一发，之后不再发射（放别的技能后又恢复）。

现状：`Scripts/Rewards/Specializations/ContentSpecializationBehaviors.cs:207-217`

```csharp
public override void Tick(float dt)
{
    if (!Context.Sprinting) { _timer = 0; return; }
    _timer += dt; if (_timer < Data.Interval) return; _timer = 0;
    Context.Services.Projectile(...);
}
```

`Tick` 是**逐帧**调用的（`SpecializationRuntime.cs:84`），`Context.Sprinting` 实时读 `SprintController.IsSprinting`（`SpecializationContext.cs:19`）→ 结构上就是"奔跑时每 1 秒发一发，直到停止"。**旧 bug 的形态（只在获取时发一次）在当前代码里不成立。**

但：`SpecializationProbe.cs:218-219` 只断言了「0.5s 不发 / 再 0.5s 发 1 发」**一个间隔**，没有"连发 3 次以上"的断言 → 不能证明长时间奔跑持续发射。

→ 建议补：连续 `Step` 3.5 秒断言 `WindShotCount >= 3`，并穿插一次"停跑清零"。

### 079 风之心持续时碰撞疯狂闪烁 —— ❌ 未修（缺归因标记）
