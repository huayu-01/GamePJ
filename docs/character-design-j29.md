# J29：玩家主攻击的伤害与暴击快照（2026-10-18）

修正近战、闪、下落攻击、落剑式与投掷攻击只填暴击字段却没有开启CanCrit、也未统一合并玩家暴击增益的问题。镰刀与长枪投掷此前还没有乘玩家DamageMultiplier。本批不调整基础平衡值。

`AttackOffense.Capture`统一冻结攻击力倍率、暴击率和暴伤。玩家基础值共读六把武器行的`CritChance=0.05`／`CritMultiplier=2`，PlayerLoadout配装时写入单位属性表；局外成长、能力卡和构筑通过既有CritChanceAdd／CritMultiplierAdd合并一次。单位构造期保留5%／2倍兜底，暴击率夹到0～1，零伤害倍率保留为有效值。射线／形状几何和基础伤害数值没有在此批调整。

| 攻击入口 | 属性冻结时机及继承 |
|---|---|
| Weapon、能量波、箭矢、拔刀剑气 | 真正发射时冻结，弹体继续使用同一AttackInstance |
| 三把B武器近战 | 每段真实ATK冻结；金光术额外剑气继承同一段快照，不重复乘攻击力 |
| 闪 | 动画Action开始冲刺时冻结 |
| 共通落 | 动画Action开始下冲时冻结 |
| 落剑式 | 继承触发它的下冲属性与已乘攻击力的基础伤害，落地不重读暴击 |
| 镰刀／长枪投掷 | 子类Launch计算蓄力倍率后冻结；后续周期与回程窗口沿用出手属性 |
| 玩家通用AttackHitbox缺省路径 | 激活时统一快照；传入现成AttackInstance时直接沿用 |

攻击生成后依然由每次RollHit掷暴击，并未把“一次攻击是否暴击”固定为全目标同一个结果。J8标记倍率和J11额外固定伤害仍按其原有命中时语义读取，不改成出手快照。

`_AttackSnapshotProbe`以真实按键和真实动画事件获取生产快照；远程与附加剑气来自真实实例化弹体，落剑式由真实World落地生成。将所取快照交给生产RollHit→Unit.ReceiveHit验证暴击和实际扣血；本专项的结算靶放在远处，故不把这一步称为全部经形状碰撞命中。原回归另覆盖完整飞行／近战／下冲与往返碰撞链。

专项覆盖三类A武器弹体、三类B武器近战、拔刀剑气、金光术附加剑气、两种投掷、闪、下冲、落剑式、玩家武器组件与通用命中盒。1.5倍攻击力、100%暴击／3倍暴伤均有实际扣血；出手后更改增益，投掷周期／回程与落剑式保持原快照。临时修改武器行基础暴击／暴伤后生效并合并真实局外加成；负暴击、零伤害、敌人通用命中盒保持原语义均有负例。
