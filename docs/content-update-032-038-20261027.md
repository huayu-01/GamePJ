# 验收032～038：内容与战斗规则更新

2026-10-27。本文记录当前实现；验收表仍由玩家填写实际体验结果。

后续039已将038的5倍跳高／2秒浮空改为3倍／0.5秒，并新增落的冷却缩减与长枪落点预览，见[039～045记录](content-update-039-045-20261028.md)。本文保留032～038阶段的历史说明。

## 032：强化、等级与护甲节点

按确认后的规则，力量每级增加15个百分点伤害加成，生命每级最大生命+20，快速每级增加8个百分点移速加成。百分比按固定值相加，力量两级为+30%，快速两级为+16%，再与其他来源的独立倍率结合。

只有这三项在第二次获取起显示“升级：名称 [等级]”；构筑面板及奖励候选均使用对应的当前/下一等级。其它增幅保持唯一获取规则，不添加堆叠角标。重复获取也会刷新已打开构筑详情。

原带“+／++”的增幅改为“升级：上一级名称”。新级应用成功后撤销前级效果实例，构筑面板只保留当前级；历史身份继续满足前置与互斥。大刀阔斧升级后为最终1.7/2.5范围倍率，不能再与旧级连乘；增生升级后为总额外2/3发。暴击、爆伤和坚硬等同样按当前级替换。

生命统一走重复的固定等级成长，历史生命+/++退出随机候选；身份与资源保留兼容。旧护甲强化也退出候选。新增独立“补充护甲”节点，发放30点护甲，单次领取，走已有节点会话与遭遇流程。它属于低价值候选，每关仍启用高2/中5/低3，共10个节点。

新增资源：`Config/Tables/Nodes/node_armor.tres`（1340）。升级配置新增强类型`Replaces`，同时必须声明直接前级为`Requires`；内容校验拒绝未登记前级和循环替换。不要用中文名称判断升级身份。

## 033：只列场景符文候选

见[16项候选清单](scene-rune-candidates-20261027.md)，包含灵魂盛宴、武装、天雷滚滚及其它可行机制，逐项写明预警、重复触发、掉落和场景边界。候选没有接入随机池，当前正式场景符文仍为8枚，每场固定一种。

死战后续的恢复、护甲、一次格挡及临时增益选项保留为另一类生存选择，本轮没有提前加入。

## 034：盾悟与铿锵

- 盾悟（异化，1337）：真实破甲后获得一次护罩，持续10秒；下一次可格挡的直接命中消耗，持续伤害不消耗。护罩有半透明表现，不产生格挡者硬直。它不会倒过来免除触发破甲的那次伤害。
- 铿锵（进化，1338）：每次成功格挡，对周围半径3米敌人造成20伤害和8强度击退。范围读取攻击范围倍率，受大刀阔斧影响；伤害和控制沿用敌人的防御、护甲及首领抗性。

两者使用`DefenseReactionRewardEffect`参数和独立运行组件，统一订阅`Blocked`事实。技能招架、普通格挡及一次护罩均可触发铿锵；主动招架额外保留既有`Parried`事实，用于原有招架反击等增幅。卸下、换装、死亡与退树时同步停止订阅。

## 035：胆小菇

新增敌人1339，使用已有`scaredy_shroom.glb`骨骼模型和独立`UnitVisualProfile`。自主移速为0，不安装保持距离走位行为；仍可承受正常外力。攻击通过真实动画事件发射6.6米/秒追踪弹，飞行上限20米，攻击后等待2秒再遁地换位。

出土点取玩家周围4～8米的有效导航位置，沿用连通性与身体净空检查；无合法点则不强行传送。行为费用由`BurrowRelocate + HomingShot`计算。原关卡白名单及死战阶段池均已接入，原来无限制的关卡白名单保持无限制。

入口：`Config/Tables/Enemies/enemy_scaredy_shroom.tres`、`Config/EnemyPlans/scaredy_shroom.tres`、`Config/VisualProfiles/scaredy_shroom.tres`。后续改骨架/模型从表现档案适配，不把美术层级写进AI。

## 025/036：持续招架与弹体反射

角色B“架”从0.75秒延长到1.5秒。真实GuardOn开启窗口；成功格挡不会提前结束，可以连续挡下多个攻击，仍保留格挡者自身短硬直。中断或到期正常收招。

敌方远程弹体先检查主动招架，再结算直接伤害或爆炸。反射保留原弹体，切换攻击者与敌对碰撞层，清理旧命中名单/追踪目标后回飞；炸弹不会先在玩家身上爆炸。反射属于衍生攻击，不冒充一次新的手动武技。

## 037：直线投枪

长虹贯日改为点按后等待真实ATK事件，向准星空间目标发射直线长枪；从枪口求方向，保留上下俯仰。预设伤害50、速度40米/秒、射程30米、击退10，基础最多命中2名敌人，冷却10秒。

气贯长虹改为无限贯穿敌人，冷却减少70%，即基础3秒；卸下后恢复原穿透和冷却。旧蓄力曲线、离手停留与召回不属于当前生产玩法。验收026/027的旧弧线和蓄力偏肩要求由本次重做替代。

技能身份和槽位保留。旧抛物线实现留在代码里供历史夹具使用，生产配置通过`LinearShot`明确选择新路径；其它武器不会共享该开关或输入状态。

## 038：浮光跃金与自动浮空

浮光跃金的瞬移上升高度固定为基础跳高5倍，仍以真实身体向上检测净空；有顶棚时只到达安全高度，不穿越地形。额外跳跃次数不再继续放大这份五倍高度。跳跃成功同时授予2秒浮空。

所有来源授予的浮空默认自动保持，不再需要按住跳跃键；上升段不受影响，空中持续时间到期恢复正常下落。按下落攻击动作取消浮空，默认Ctrl，可在设置的“下落攻击 / 取消浮空”项改键。取消不吞输入，角色B可以在同一次按键中开始下落攻击。

高度倍率与浮空秒数位于`TeleportJumpRewardEffect`；来源租约单独保存参数，撤销后恢复原跳跃模式。角色A跃升的说明也同步为自动浮空规则。
