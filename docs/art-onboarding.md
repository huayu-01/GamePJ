# 美术接入与制作流程

制作源文件入口为 [ArtSource](../ArtSource/README.md)，目录和依赖约定见[资源规范](assets.md)。当前方向为明亮自然环境与动漫三渲二，后续造型以用户最新裁定和对应资产说明为准。

角色建模前先读[参考方法与制作经验](../ArtSource/modeling-notes.md)。2026-10-25用户明确要求多找参照物模仿，“换皮不换骨”：先对齐参考的比例、轮廓、体积和结构关系，再替换本项目的外观识别元素。本轮三叶旅童的返工经验与当前边界已记录，后续继续积累。

2026-10-26用户进一步要求：文字描述并不包含全部设计细节。制作前逐项拆解参考的比例、截面、弧度、厚度、叠压、负空间和材料表现，再从灰模到局部逐层对照；交付必须附多视图与差异复盘，不能只做出“符合描述”的部件就收工。完整拆解与验收方法已写入上述经验页。现有敌人的[美术计划书](enemy-art-plan.md)目前为文字候选，按“描述挑选与整改→生图筛选→逐个设计制作”推进。

2026-10-24用户补充：另一个会话新增的重击、重击Plus、蘑菇为当前确认模型；其余模型（含当前角色）尚未确定为最终稿，造型、骨架、骨名和层级均可能更改。现有模型属于接入样例，不能据此固定后续资产规范或把文件路径写进战斗逻辑。确认外观也不等于所有生产场景和行为已经验收。

2026-10-26更新覆盖上述旧选择：用户取消持锤重击石人，后续保留纯岩块Plus方向。角色主题明确为魔幻丛林，果壳、叶片、藤蔓、根须、树皮和苔石应参与形体结构。首批概念图选择为E01-B、E03-B、E07-A、E15-A，先看E01-B；详见[美术计划书的最新选择](enemy-art-plan.md#选择记录)。

骨架模型通过 `UnitVisualProfile` 声明模型、骨架／播放器路径、握持挂点与动画库。更换模型后先运行 `content` 检查实际绑定，再运行 `replacement`／`replacement_render` 检查挂点运动、事件帧、真实伤害和换装清理。测试读取档案和当前技能依赖，不固定某个角色模型目录、骨名或动画数量。骨名发生变化时仍需重定向动画；同名骨骼的层级调整可以按档案重新定位，结构通过不代替动画与造型质量评审。

当前自动处理只负责同名骨骼的路径重定位。即使骨名相同，静止姿态、骨轴或比例发生变化时也可能需要重新定向动画并复核握持；这套入口不会自动适配任意骨架，也不要求未来模型沿用当前骨名。

1. 固定英文资产Id，保存确认的概念图、生成参数、原始模型、来源与许可。
2. Blender整理拓扑、材质、脚底原点、尺寸及朝向；保留可编辑主工程。
3. 按行为制作起手、发力、恢复、受击和死亡动作。非人形使用适合自身结构的骨架。
4. 导出GLB并核对Godot导入设置；快速动作保留已经验证的60fps采样。
5. 通过独立表现预制接入真实Unit／Ability；伤害和格挡仍等待ATK／GuardOn等真实事件，不能只播放演示动作。
6. 按最终碰撞体尺寸复核导航、生成净空和狭窄通路。
7. 在实际玩家镜头、普通战斗和多敌群战中检查预警、遮挡、击打材质、音色、特效强度和性能。

现有样板：[森林环境](../Scenes/Levels/NatureBenchmark/README.md)、[120米森林场地](../Scenes/Levels/NatureArena/README.md)、[真实重击样件](../Assets/Enemies/StoneSlammer/README.md)、[蘑菇与法师](enemy-models-first-pass.md)、[石头人Plus](stone-golem-plus-pipeline.md)。这些资产的正式接入程度各不相同，演示验证不等于生产战斗验收。

三叶旅童已作为[角色A森林战斗试装](clover-combat-trial.md)接入：真实基础动作、Chest悬浮武器焦点和额头释放闪光。独立场景临时选择视觉档案，正式猎手配置尚未替换。技能适配保存原事件时刻，基础动作的升降仍由真实物理控制。

动作表现支持[外轮廓模糊与稀疏撕边](anime-motion-preview.md)，已封装为[函数与动画事件组件](motion-fx-authoring.md)。视觉档案选择预设即可接入，石头人森林实战场已使用真实事件驱动，保留原模型与战斗状态。

当前UI外观入口为[UI契约](ui.md)；正式交互物已替换为[类型组件生成的新模型](interaction-authoring.md)，各类型使用不同几何，价值环颜色与波数共读ValueTags。角色展台重建台座，人物与武器仍读角色／武器配置。战斗反馈见[打击反馈](combat-feel.md)。旧资源示例、素材研究和历史接入过程已[完整归档](archive/reference-before-2026-10-21/art-onboarding.md)。
