## 场景交互制作

`InteractionComponent` 可作为子节点挂在普通 `Node3D` 或 `Area3D` 下，`Kind` 选择16种内置定义；也可直接指定 `Definition` 安装新的后端和模型，此时允许Kind为None。它复用现有交互契约；有Area时使用真实重叠，没有时使用半径，仍走近按F。自定义机关用 `Signal` 类型连接 `Triggered`。

正式基地七个交互物（原冒险出击／生存试炼／能力矩阵／帮助、两角色展台、符文台）、森林10个奖励与首领门、动态出口均由类型组件生成新模型。各类型使用不同几何，编辑器选Kind可预览；不再接线HighlightMesh／HideOnUse。角色本体及武器仍由CharacterConfig／WeaponConfig驱动，展台结构重新生成。旧模型只保留给Main／历史专项，正式场景已移除旧模型实例引用。Stage递归收集嵌套后端，布点通过MoveTo移动整个宿主。[接入手册](interaction-authoring.md)含类型表、触发器、模型与示例。

挑战开始显示金色身体粒子与右上真实预算／波次面板；真清场后撤销粒子并播放绿波、音效及完成提示。挑战期间对其他交互按F，自动红罩、闪红抖动、碰撞弹开与失败音效，不消耗目标。组件导出FailureKnockback／FailureWaveRadius／FailureWaveSeconds。失败、停止、复位、死亡和退树不冒充成功；还有预算的限定多波不会在波间空场提前完成或卡住续波。
