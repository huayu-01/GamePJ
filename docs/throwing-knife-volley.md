# 飞刀名称与固定散射夹角（2026-10-22）

用户要求将原武器相关名称换为飞刀，并将右键发射散布固定限制在一个预设60°的总夹角内，不随飞刀数量增加而扩大。

## 当前规则

- 武器显示名“飞刀”，升级池“飞刀升级池”；左键“飞刀散掷”，右键“千刃齐发”。武器、武技及“专一／花心／心流”的玩家说明统一使用飞刀。生产配置、源码注释和当前维护文档同步；历史交付日志和归档保留原文。
- 右键参数位于 `Config/Tables/Skills/skl_a2_w1_2.tres` 的 `SpreadAngleDegrees`，默认60°，表达左右外沿之间的总夹角。相邻间距 = 总夹角 ÷（最终数量−1），单刀沿准星中心发射。
- 默认3／5／7／9把的相邻间距分别为30°／15°／10°／7.5°；扩展到更多飞刀时仍只变密。扇面随三维准星俯仰，接近竖直瞄准时使用备用轴，保持扇形宽度。
- 固定范围约束发射初速。“花心”分配目标后仍在扇面内出手，之后继续按原规则追踪；“专一”和“心流”最终只有一把时居中。
- 左键保持3把、相邻20°；伤害、蓄力、动画ATK、下坠、击退和进化规则沿用既有设计。
- 共用的 `ArrowVolleyAbility` 新增可选固定总角度，默认−1保留原相邻夹角模式；只有飞刀右键启用60°。`LastSpreadDegrees` 明确记录相邻夹角，`LastSpreadAngleDegrees` 记录总夹角。
- `wpn_crossbow`、`pool_crossbow`、技能Id、枚举数值及现有资源路径保留，避免旧配装存档和资源引用失效。本次是名称和发射规则调整，现有模型、动画和投射物美术不作为新飞刀美术交付。
