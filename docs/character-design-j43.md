# J43 灵剑命中后有序三连刺

依据2026-10-21试玩反馈，替换[J42](character-design-j42.md)的外圈随挥：三柄灵剑有序冲向玩家攻击命中的目标，强调短促、刚猛的刺击，模型改为瘦长针状剑。持续与灵能汲取规则沿用，不创建新对话。

## 当前效果

- 本人的主攻击真实命中一名存活敌人后锁定该目标。三剑固定按中→左→右出手，间隔0.12秒；每剑短蓄势0.065秒、反向拉弦0.3米，再以85米／秒高速直刺。飞行遵守全局实际弹速上限，接近目标后锁定最后一段直刺，不减速盘旋。
- 三剑各自真实扫掠并命中一次，命中后短促贯穿约0.045秒，关闭伤害，再用1.1秒缓慢归位；全部归位后才能响应下一次命中。出手中的新命中不抢占、不排队补发。挥空只有ATK时不出剑。
- 剑刃长2米、最大宽0.15米，长宽比约13.3；窄剑格与短剑柄保留武器识别。待机略呈扇形，出手时针尖对准目标；配合短亮核和约0.13秒的速度尾迹，第三击更重。
- 命中使用既有肉体／护甲／破甲／格挡音效、接触亮核与镜头反馈，三击重量为1.45／1.45／1.8。伤害仍为触发攻击基础快照的30%／剑，完整继承该次连招段和暴击参数，不重复乘攻击力；本轮没有用增伤来代替视觉重量。
- 灵剑脱手后使用独立物理时钟，不跟着玩家后续近战的局部顿帧暂停；不会反过来冻结玩家的挥剑动作。

持续10秒、召唤成功起算15秒冷却，“灵能汲取”本人击杀敌人续时2秒保持。没有灵剑时不储存续时；冷却结束但效果仍存在时不叠组。技能`skl_b1_w1_2`、奖励`evo_great_draw`与原池引用保持。

## 边界与接入

三剑在伤害结算后锁定同一轮最先接收的本人主攻击存活目标，不重新搜索附近敌人，也不由灵剑自己、持续伤害或派生伤害递归触发。护甲／格挡等接触仍可触发，实际灵剑伤害继续由统一防御结算决定；无敌规避或本次已致死的目标不会启动追击。直接环境扣血没有攻击快照，不启动追击。

目标死亡、释放或离玩家超过18米时，待发及飞行中的剑收回，不自动换打旁人；飞行还有0.65秒超时。剑体对World做形状运动查询，被墙体挡住就收回；`AttackHitbox.RequiredTarget`只允许伤害锁定敌人，路径旁人和友方不受伤。归位／贯穿收尾无额外伤害。换装、禁用、死亡、退树均清理飞行、待发、伤害和总线订阅。

`GameplayEvent.Hit／Damaged`携带可选的`AttackInstance`原始快照，使追击从真实结算事实取得目标和属性，不反查库存技能。追击只订阅结算后的Damaged，并检查生命仍大于0：结算顺序中Health已归零时，IsDead可能尚未置位，不能单独依赖IsDead。撤去J42专用的`MeleeComboAbility.StrikeStarted`接线。`SpiritSwordsAbility`负责独立剑状态，`SpiritSwordFx`只处理材质亮核和运动尾迹。调参仍在`skl_b1_w1_2.tres`，统一反馈配置保持原有上限与限频。

首次完整Main另外发现结算顺序问题：前一项测试的残留靶20生命先承受40伤害，提前被Hit锁定；其死亡使同次攻击的活靶被忽略。修正为结算后选择存活目标，保留原Main场景与顺序，新增同次攻击先杀弱怪、后打活靶的真实结算／物理突刺检查，没有删去或跳过原断言。

第二次Main在另一组暴击结果下，残留靶先剩17生命，三剑正常锁定它并在第二剑将其击杀，第三剑按设计取消。主场景夹具现等待前一连招真正收招，并在召唤前清理该项自己的旧靶，再布置100000生命的新靶；三剑／顺序／来源断言继续严格保留。即时冷却比较`EffectiveCooldown`，保留表冷却15秒检查，允许角色已有冷却属性生效（该轮实际13.5秒）。本次最后改动仅为SelfTest隔离与校验，995项游戏专项均已通过，随后定向复验Main，不重复无变化的专项。

定向复验前还遇到并行新增的`StoneSlammerShowcase.cs`调用受保护`Ability.Cancel()`而无法编译，已最小改为公开`ResetForLoadout()`入口，保持暂停展示时取消动作并恢复冷却的目的。该展示脚本仍属于外部未跟踪工作，不混入本批提交；对应构建失败记录保留。
