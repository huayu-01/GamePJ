# J33 · 单位身体碰撞与快乐小子

2026-10-19用户纠正：单位之间本来需要实体碰撞；玩家／敌人攻击盒按阵营过滤，子弹检测敌对单位与地形。用户同意快乐小子将穿透改为奔跑接触轻推普通敌人。后续先重点设计画面与模型，其他机制审查暂停；飞行、压低高度和打落作为后续设计需求记录。

新增UnitBody第10层（512），Unit身体同时保留PlayerUnit或EnemyUnit受击身份，Mask统一World＋UnitBody（513）。双方和同阵营单位互相阻挡，攻击盒继续只查敌对阵营；玩家子弹Mask仍是World＋EnemyUnit（5），敌方子弹为World＋PlayerUnit（3）。同一物体可占多个层，无需把敌人放到地形层。身体配置统一位于Unit._Ready，未批量改动外部场景。project.godot只提交新增层名。

快乐小子新增真实生产行mut_happy_runner，非重复异化，无符文前置。奔跑时读取真实MoveAndSlide接触，普通敌人经ReceiveKnockback轻推，无附加伤害，不推动首领；同一敌人有0.5秒间隔。推速5m/s是可调预设。实际受伤后等待10秒，再在奔跑时每秒恢复1生命，护甲／护盾受伤也重置等待，回血尊重禁疗。没有额外无敌、虚化或穿墙。换装清理节点及订阅。生产目录从90增到91=23强化／33进化／35异化，符文仍独立11枚，23项特化不变。

原D批无阻挡契约已按新裁定迁移：普通移动与剑突被身体挡住，攻击仍可在身体接触前沿命中；显式穿单位的“闪”保留，只查地形，完成或取消后恢复身体Mask。原测试0.4秒采样可能处于动画启动后的冲刺中，现在等待真实PierceApplied结束后再验证恢复。没有改动技能伤害、范围、动画时长或降低断言数量，层名新增使D批90增为91项。

飞行单位不会因为使用身体层就无限阻挡地面路径，实际由三维位置与形状决定。专项验证了不同高度可通过、相同空中高度仍阻挡，以及受力入口XYZ分量保留。此处不是已实现飞行控制或打落系统；后续飞行模式、持续力、质量与抗击退／霸体应分开定义，详见[碰撞与受力约定](collision-layers.md)。

失败现场保留：首次新探针的“同高度空中”测试在角色表延迟覆盖重力前设置了0重力，修正为等配置就绪后再隔离；旧D批强制身体重叠导致物理脱离方向影响近战站位，改为真实身体接触前沿，且恢复Mask改为观察实际冲刺结束事件。

Main前两次完整回归的八指标虽一致，但J8出现额外命中失败，现场另存105513与110234日志。旧靶子在入树前关闭物理回调，初始化后仍开始追击；入树后关闭Brain与Movement仍不足以解决其放大球体挤开玩家的问题。最终固定靶保留Enemy受击层、真实弹道和Unit状态倒计时，测试球体不加入UnitBody；实体阻挡由31项身体专项和91项D批验证，不降低任何命中断言。验证脚本同时增加J33的J8红标门禁，避免八指标通过掩盖此类失败。仅测试夹具变动后可用-BodyCollision -MainOnly保留双构建、独占和存档保护单独复核Main，证据另存。
