## 068：风之领域与旋风

风之领域（原1244）不再监听镰刀离手／停留事件。携带风之印后，六种武器均可获取；有正式浮空状态且在空中时，旋风出现于角色下方的导航地面。普通跳跃不凭空生成浮空，找不到下方有效地面时不在世界原点或半空伪造旋风。

范围沿用5米、每0.5秒15基础伤害，可受狂风放大。角色处于旋风接触高度（预设3米）时，每1秒最多延长当前浮空2秒；没有浮空或浮空已取消时不会重新授予。浮空取消、落地或奖励撤销后停止领域。按原文“每1秒延长2秒”，持续保持接触可持续续航；本轮没有暗加总时长上限。

所有旋风区域对进入其中的双方投掷物减速75%，离开恢复原速；重叠区域取最强减速，不反复乘到接近零。减速影响真实轨迹推进、重力与制导，不修改技能的原弹速参数；投射物寿命仍按游戏时间消耗。区域退出后解除注册，无旋风时没有额外节点或逐帧全场搜索。

### 补给与结算

补给选项是`SupplyOptionDefinition`资源，内容、两个模式权重、数值、状态引用和显示名独立维护。生命10、护甲20、力量+30／30秒、速度+20个百分点／15秒、急速冷却×0.5／15秒、经验20（死战）、碎片5。普通冒险在抽取前排除经验；每份只有一种内容。

力量／速度／急速复用统一状态系统与状态视觉；同类刷新时间不叠幅度，到期仅撤自己的修正。力量的30按本次直接出手在多弹／组成段间分配，冻结在出手快照；不会每一枚飞刀额外领取30，也不会给自动电链附加30。暴击、标记等仍沿既有伤害链处理。驻枪的持续接触不反复领取药剂预算。

补给碎片和“碎片”强化共用`RunController.CollectedBonusShards`本局账本；死战击杀碎片仍由导演保留独立来源。HUD显示合计已拾取量，结束时各来源只合并一次；未拾取不计收益，取消不写局外，普通冒险与死战语义相同。

## 070：有效位置审查

已有严格实现，位于`Scripts/World/MapManager.Navigation.cs`及`Scripts/Encounter/SpawnPlanner.cs`，无需再创建另一套“射线命中就算有效”的寻路逻辑。

| API | 语义与正确用途 |
| --- | --- |
| `TryNavigationAnchor` | 取得该体型导航图上的邻近锚点。仅是投影，不保证原点距离、净空或最终可站立性，不能直接当最终瞬移落点。 |
| `TryGroundAnchor` | 本轮补充。沿下方有界采样导航投影，过滤高于角色的点与横向偏移，避免空中最近点被远处屋顶吸走；它仍是锚点，最终单位落点继续校验连通和净空。 |
| `TryValidPoint` | 在投影距离、高差、完整连通路径与身体净空都合格时返回落点。适合地面单位、瞬移、可接近补给。 |
| `TryPath` | 检查导航点拥有者、两端容差及路径是否真正到达终点；邻近但分属孤立区域不会伪装成可达。 |
| `HasBodyClearance` | 按单位实际世界缩放与碰撞体检查净空，排除自身。大体型会选择对应体型的导航图。 |
| `TryRingPoint` | 有限次数在半径环内采样，再走严格有效点验证；最终水平距离仍须在范围内。 |
| `SpawnPlanner.TryFindSpawnPoint` | 在严格环形选点上增加同批预留间距，避免物理帧尚未更新时重叠生成。 |

新金蝉脱壳以玩家水平坐标为范围中心，导航锚点只提供高度和连通参照；避免高空最近点横向偏移导致实际瞬移超出半径。新空投使用同一严格入口，失败本周期不生成；秘法切刃先保存合格回退点，终点在最后目标周围找净空，不直接站进目标身体。

斜阳的墙面／天花板属于“合法命中表面”，不是可行走导航落点。其指示器和刺落读取实际World碰撞点与法线；角色不传送到墙面，因此不拿导航网格伪造墙面法线。射线只用于表面选择、遮挡和真实弹道碰撞，没有替代寻路。

保留的旧`SpawnPlanner.FindSpawnPoint`返回值API带无地图时的随机兜底，不适合新增关键落点流程。新内容只调用`Try*`严格接口；导航未准备好、无有效点、身体太大或区域不连通时允许失败，避免静默落到世界原点、墙内或不可达位置。
