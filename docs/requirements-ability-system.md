## 一、能力系统重做（**参考哈迪斯 2 的卡牌系统**）

用户原话：

> 「现在需要调整一下"**能力**"这个东西，它应该跟**哈迪斯 2 里的卡牌**是差不多的，这些能力**都可以被解锁**，之后可以通过**局内获取的局外资源来升级**，然后这些能力是**可激活或关闭**，**激活时占用一定的额度点数**，而**玩家持有一定额度**，**额度也是可以被局外资源升级扩增**的，之前的相关参数表可能也要连带着做调整」

### 要点拆解

| 概念 | 说明 |
|---|---|
| **能力（Ability）** | 类似哈迪斯 2 的**卡牌**。是**局外**的东西（不是关卡内的临时技能） |
| **解锁** | 能力有"未解锁"状态，需要用**局外资源**解锁 |
| **升级** | 已解锁的能力可以**多次升级**，消耗局外资源 |
| **激活 / 关闭** | 玩家可以选择**装备哪些能力**（有开关） |
| **额度点数（容量）** | 每个能力**激活时占用一定额度**；玩家总额度有限 → **必须取舍** |
| **额度可升级** | **额度上限本身也能用局外资源扩增** |
| **参数表要调整** | 现有的能力/技能相关配置表（`Skills/` 25 行、`Config/Tables/`）**要连带着改造** |

⚠️ **注意与现有系统的关系**：现在 `Config/Tables/Skills/` 里的 25 行是**单位技能**（5 玩家 + 16 单位 + 4 首领行为）。本需求说的是**局外卡牌式能力**，可能是**另一层**（局外装备 → 影响局内），**不要直接混进 `Skills/`**，先判断两者关系再动手。

## 二、能力矩阵 UI 布局与交互（**这是本轮最大的 UI 工作**）

用户原话：

> 「之后就是这个的 UI 布局元素，大概就是像**卡牌一样展开矩阵排序**，比如 **5×5 / 6×6 / 3×6 / 6×4** 这样的**全屏矩阵**，这样每个元素视觉上都比较大」

### 交互逻辑（用户要求做进**基类**）

> 「这些要做进类似的**基类**（如果 godot 里附带了则无视我说的这段）」

**元素三个状态**：

| 状态 | 视觉 |
|---|---|
| **未解锁** | **变暗** |
| **解锁未激活** | **恢复颜色** |
| **激活** | **有一圈光圈** |

**操作与反馈**：

| 操作 | 行为 |
|---|---|
| **左键长按**（未解锁元素） | **读条** → 读条结束判定资源是否足够 → **不够则震动一下元素** → 够则**解锁**并播解锁视觉（略微放大 / 闪一下 / 3D 翻转，**都是缓动**） |
| **左键**（未激活状态） | **激活** |
| **右键** | **升级**（资源不够 → **震动**） |
| **右键长按**（已升级多次的元素） | **读条** → 读条结束**重置升级进度**并**归还升级消耗的资源** |

**通用规则**：
- **失效/失败的交互都要震动对应元素**
- **震动、点击、升级等行为都要有对应音效**
- 元素有**边框**，**边框颜色表示等级**：

| 等级 | 颜色 |
|---|---|
| 0 | **灰** |
| 1 | **白** |
| 2 | **绿** |
| 3 | **蓝** |
| 4 | **紫** |
| 5 | **红** |

- **光圈在边框外亮起，光圈颜色与边框对应**
- ⚠️ **制作时预留足够的间隔**

## 五、16 项具体问题与调整（**逐条**）

### 1. 枪手技能没有朝准星走

> 「枪手的技能没有对着准星的位置走，比如我选了狙击枪，然后按 E，**子弹没有对着我的准星走**」

⚠️ 注意：之前修过"角色持续朝向准星"，但**子弹方向**可能仍不对。要查 `AbilityBurst` / `Weapon.AimPoint` / 弹道初始方向的实际取值。

### 2. 跳跃参数

> 「跳跃的**高度应当在高一些（+40%）**，**速度要更快一些（+100%）**」

### 3. 死亡流程

> 「玩家死亡时 → **进死亡动画** → 然后进**演示动画**（相当于**场景切换的过渡**，目前没有可以给个**简单的面板做占位**）→ **回到基地**」

### 4. 基地里切换装备/角色时，玩家模型实时切换

> 「在基地时选取了什么装备/角色时，**玩家就切换到相应的目标**，方便进关卡前熟悉角色」

### 5. 白板首领不该频繁出现

> 「刷新的怪物总是会出现**白板首领**，但是白板首领应该是**要很久才出现的，基本只在第 8 波怪刷出**」

⚠️ 现在每场 Encounter 末尾都出白板首领 → 要改成**只在高波次（如第 8 波）出现**。

### 6. 关卡内定期刷怪 + 每 120 秒增强

> 「让我们调整一下节点刷怪的节奏，**当角色进入关卡时，场景里会定期在任意有效位置刷出怪物**，**每过 120 秒（可调整的参数）就增强接下来刷出的怪物**（提升强度或更强类型的怪）」

这是一套**新的"压力递增"机制**（与节点的 Encounter 并存）。

### 7. 节点刷怪波次按价值标签

> 「节点刷怪调整，**高价值节点会刷 4 波怪，中刷 3，低刷 1**，对应**异化 / 升级 / 双倍强化 / 多倍资源强化 / 特殊奖励 / 双倍资源恢复 / 一倍资源**；这些**不写死**，假设后期有彩蛋或其他奖励也会在这些不同的价值标签里」

⚠️ 现在的映射是 **高3 / 中2 / 低1**，要改成 **高4 / 中3 / 低1**，并且**按"价值标签"驱动**而不是按枚举硬编码。

### 8. 护甲的血条表现

> 「玩家和怪物**有护甲时血量上应该要有其他效果来显示护甲的进度和碎甲效果**，甚至是**模型的额外显示效果**」

### 9. 伤害数字分类显示

### 10. 操作模式切换（锁定/不锁定）
