## 后续地形与能力门槛设想（用户提出，尚未定案）

交互节点必须被玩家实际接近，因此地形本身可以参与成长与风险选择。后续地图需要专门设计，当前美术样板的地形不能直接视为最终关卡方案。

- 可以考虑玩家初期没有跳跃能力，获得跳跃后才能到达高处的高价值节点。
- 可以考虑构筑开启路线，例如雷系技能打碎可攻击的岩石，进入原本封闭的地形。
- 可达性不仅由寻路网格决定，还可能取决于跳跃、位移、攻击属性和可破坏物状态。

以上为后续方案记录，**本轮不关闭现有跳跃，也不实现雷系破岩或构筑地形门**。是否采用、何时获得能力、能力是否跨局保留、具体门槛与奖励分布，需要在专门的关卡设计中确定。

设计时应检查：主要通关路线有无可靠的基础通路；可选奖励是否允许当局放弃；随机构筑能否导致软锁；单向跳落后的回程；高价值节点拿到奖励后是否有合适战斗空间；敌人寻路与玩家专属通路的关系。门槛必须在玩家投入路程前有清楚的视觉线索。

## 近期可验收流程

基地选择与练习 → 出击摘要 → 森林探索 → 看懂节点收益类型和代价 → 先选奖励后挑战 → 再选择一次构筑 → 自主决定挑战首领 → 稳定离场／死亡结算 → 回基地成长 → 再出发。

建议目标时长为10至15分钟；这属于待实测的体验目标。当前不以自动化推进代替完整游玩评价，不因机制或模型样件验证通过而宣布整条体验已经完成。
