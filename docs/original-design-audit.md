# 原始角色设计重新核验

2026-10-17。需求来源：`F:\Godot项目\3d肉鸽雨中哈迪斯\角色设计.txt`，以及用户后续澄清。旧批次测试通过只证明原测试条件成立，不能据此认定原始需求全部对齐。

## 本轮用户确认

- 镰刀仍有武器大师共通被动“落”，没有灵剑的额外落地攻击圈，也没有长枪的准星定向下冲。
- 能量掌武技2松右键释放，以松手时机判断普通或完美；不使用闭合期左键触发完美的旧描述。
- 长枪武技2基础蓄力1秒，额外最多1秒，每0.25秒增强一档，合计最多2秒、4档增强。
- 长枪武技1是挥砍→上挑→下劈→突刺的四段循环。
- 默认长枪投出后落地静止，再次使用才召回；召回路径造成伤害。“气贯长虹”进化才改成落地自动召回。
- 镰刀武技2向前飞一段距离后停留，持续旋转并周期伤害，再次使用或靠近召回。
- 共通“落”按下瞬间，以角色脚下到地面的真实高度计算伤害；不使用已下落距离。
- 后置蓄力按基础值加算：长枪4档为1.8倍，弓5档为2.5倍。不是逐档乘方。
- 长枪准星选目标落点；超过本次蓄力射程时截到同方向最远处。
- 发散的标记层数提高能量掌武技1“波波”伤害；原文漏写了“武”字，不提高后撤伤害。
- 变奏获得后新增点按快射，不用先等0.5秒；连续点按按1→2→3循环，长按仍走蓄力。
- 动作打断：用户确认，未明确说明不可打断的动作默认可被后来动作打断；例外用强类型表开关配置。后台效果、已经离手的武器继续独立运行。

## 新探针先验失败与已修正项

`CharacterDesignProbe`修正前16通过/20失败：六配装每种有三个转镜头方向不转身，镰刀和长枪错误启用落剑式。模型两脚脚尖的世界前向与逻辑前向点积均为1，模型轴向没有翻反。

修正后无头42/0：六配装四方向、模型朝向、灵剑专属落圈开关、后撤期间不随镜头转身及结束释放锁；长枪真实输入→动画ATK→两轮伤害事件的段序列为`0,1,2,3,0,1,2,3`，目标生命10000→9804.199。长枪前四段预设数值保留，去掉旧重复第五段。

J2补入投掷同源模型显示与手持隐藏；长枪四档基础加算1.8倍、弓五档2.5倍，真实输入／ATK／窄目标往返扫掠已验。见[J2验收](character-design-j2.md)。当前仍共享阶段性的原生近战动作；四种挥枪动作的视觉区分、独立投掷动作和下落改型还需继续完成，不能把段序列正确写成全部动画表现已完成。
