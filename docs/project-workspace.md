# AI工作目录与验证资料

2026-10-27已将项目根目录216项 `.ai*` 历史资料集中到 `.ai/`：148个目录进入 `workspaces/`，68个文件进入 `files/`。原名和资料均保留，迁移清单记录了各原路径、新路径、文件SHA256和1167个内部联接。迁移后文件哈希与联接核验通过，五份真实存档不变。

目录约定：

| 目录 | 用途 |
| --- | --- |
| `.ai/workspaces/` | 历史验证工程、基线、后续新建隔离验证镜像。 |
| `.ai/files/` | 根目录迁入的历史脚本、补丁、清单及旧锁文件；保留作记录。 |
| `.ai/locks/validation.lock` | 当前构建和游戏验证共同使用的互斥锁。 |
| `Logs/runtime/` | 游戏运行日志。 |
| `Logs/validation/` | 构建、导入和验证进程输出，以及短期验证文件。 |
| `Logs/evidence/` | 验证结果、截图和正式证据。 |
| `Logs/maintenance/` | 维护工具、修改前副本和过程资料。 |

`.ai/.gdignore`及C#项目排除规则阻止编辑器和编译器重复扫描历史工程；`.ai/`已加入Git忽略。不要把其中的历史脚本作为当前入口，也不要递归遍历联接目标来批量清理。

后续使用 `_tools/` 下的正式验证入口。公共设施自动把新镜像放入 `.ai/workspaces/`，使用同一把验证锁。角色及美术验证脚本也已切换到公共锁，输出进入 `Logs/validation/`，不再在根目录生成散落的 `.ai_*` 文件。

迁移工具 `_tools/consolidate_ai_workspace.ps1` 默认只预览，加 `-Apply` 才移动；会检查绝对路径、占用进程、目标冲突和联接。此次记录位于 `.ai/migration-20261027.json`。工具只管理自身启动的验证进程，不关闭用户编辑器。
